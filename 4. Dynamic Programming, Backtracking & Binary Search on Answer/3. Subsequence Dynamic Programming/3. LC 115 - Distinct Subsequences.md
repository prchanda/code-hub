Question: https://leetcode.com/problems/distinct-subsequences/description/

```cs
public class Solution {
    public int NumDistinct(string s, string t) {
        int[,] dp = new int[s.Length + 1, t.Length + 1];
        
        for (int row = 0; row <= s.Length; row++) {
            dp[row, t.Length] = 1;
        }

        for (int row = s.Length - 1; row >= 0; row--) {
            for (int col = t.Length - 1; col >= 0; col--) {
                if (s[row] == t[col]) {
                    dp[row, col] = dp[row + 1, col + 1] + dp[row + 1, col];
                } else {
                    dp[row, col] = dp[row + 1, col];
                }
            }
        }

        return dp[0, 0];
    }
}
```

### Complexity Analysis

- **Time Complexity:** $O(N \times M)$, where $N$ is the length of string $s$ and $M$ is the length of string $t$. The nested loops iterate through all possible index combinations of both strings.
    
- **Space Complexity:** $O(N \times M)$, used by the 2D dynamic programming table of size $(s.Length + 1) \times (t.Length + 1)$.
