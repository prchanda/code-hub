# Top-Down approach using memoization

```cs
public class Solution {

    public int LongestCommonSubsequence(string text1, string text2) {

        int[,] dp = new int[text1.Length, text2.Length];

        for(int row=0; row< text1.Length; row++)
        {
            for(int col=0; col< text2.Length; col++)
            {
                dp[row,col]=-1;
            }
        }
        Solve(0,0, text1, text2, dp);
        return dp[0,0];
    }

    private int Solve(int i, int j, string text1, string text2, int[,] dp)
    {
        if(i==text1.Length || j == text2.Length)
            return 0;  

        if(dp[i,j]!=-1)
            return dp[i,j];

        if(text1[i]==text2[j])
            dp[i,j] = 1 + Solve(i+1,j+1,text1,text2, dp);
        else
            dp[i,j] = Math.Max(Solve(i+1,j,text1,text2,dp), Solve(i,j+1,text1,text2,dp));  

        return dp[i,j];
    }
}
```


# Bottom-up approach

Explanation : https://www.youtube.com/watch?v=Ua0GhsJSlWM

```cs
using System;

public class Solution 
{
    public int LongestCommonSubsequence(string text1, string text2) 
    {
        int rows = text1.Length;
        int cols = text2.Length;

        int[,] dp = new int[rows + 1, cols + 1];        

        // Base cases: initializing last column and last row with 0s
        for (int row = 0; row < rows; row++)
        {
            dp[row, cols] = 0;
        }

        for (int col = 0; col < cols; col++)
        {
            dp[rows, col] = 0;
        }

        // Bottom-up Dynamic Programming
        for (int row = rows - 1; row >= 0; row--)
        {
            for (int col = cols - 1; col >= 0; col--)
            {
                if (text1[row] == text2[col])
                {
                    dp[row, col] = 1 + dp[row + 1, col + 1];
                }
                else
                {
                    dp[row, col] = Math.Max(dp[row + 1, col], dp[row, col + 1]);
                }
            }
        }

        return dp[0, 0];
    }
}
```

### Complexity Analysis

Let $m$ be the length of `text1` (`rows`) and $n$ be the length of `text2` (`cols`).

- **Time Complexity:** $\mathcal{O}(m \times n)$
    
    - Initializing the base case boundaries takes $\mathcal{O}(m + n)$ time.
        
    - The nested loops iterate $m \times n$ times, performing constant-time $\mathcal{O}(1)$ operations in each step.
        
- **Space Complexity:** $\mathcal{O}(m \times n)$
    
    - The 2D array `dp` requires storage of size $(m + 1) \times (n + 1)$ to hold the subproblem states.
        

> **Tip:** Space complexity can be optimized to **$\mathcal{O}(\min(m, n))$** by keeping track of only two 1D rows (or 1D array with a temp variable) since calculating state `dp[row, col]` only depends on the current row and the next row (`row + 1`).


```cs 
// Two-row implementation (at any point in time we are using the current row and use the next row for calculation)

public int LongestCommonSubsequence(string text1, string text2)
{
    int rows = text1.Length;
    int cols = text2.Length;

    int[] next = new int[cols + 1];
    int[] curr = new int[cols + 1];

    for (int row = rows - 1; row >= 0; row--)
    {
        for (int col = cols - 1; col >= 0; col--)
        {
		    if (text1[row] == text2[col])
            {
                curr[col] = 1 + next[col + 1];
            }
            else
            {
                curr[col] = Math.Max(
                    next[col],
                    curr[col + 1]
                );
            }
        }

        // Current row becomes the next row
        // for the next iteration.
        (curr, next) = (next, curr);
    }

    return next[0];
}
```
