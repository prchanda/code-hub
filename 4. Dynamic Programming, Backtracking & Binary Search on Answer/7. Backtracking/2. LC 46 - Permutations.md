Question: https://leetcode.com/problems/permutations/

Explanation: https://www.youtube.com/watch?v=FZe0UqISmUw

```cs
public class Solution 
{
    public IList<IList<int>> Permute(int[] nums) 
    {
        IList<IList<int>> result = new List<IList<int>>();
        IList<int> current = new List<int>();
        bool[] used = new bool[nums.Length];

        DFS(nums, used, current, result);

        return result; 
    }

    private void DFS(
        int[] nums, 
        bool[] used, 
        IList<int> current, 
        IList<IList<int>> result)
    {
        if (current.Count == nums.Length)
        {
            result.Add(new List<int>(current));
            return;
        }

        for (int i = 0; i < nums.Length; i++)
        {
            if (used[i])
            {
                continue;
            }

            used[i] = true;
            current.Add(nums[i]);

            DFS(nums, used, current, result);

            used[i] = false;
            current.RemoveAt(current.Count - 1);
        }
    }
}
```


**Time Complexity**

- **$O(N \cdot N!)$** where $N$ is the length of `nums`.
    
    - There are $N!$ possible permutations generated at the leaf nodes of the recursion tree.
        
    - Creating a copy of `current` (`new List<int>(current)`) at each completed permutation takes $O(N)$ time.
        

**Space Complexity**

- **$O(N \cdot N!)$** total space, or **$O(N)$** auxiliary space.
    
    - **$O(N)$** auxiliary space for the recursion call stack (up to depth $N$), the `used` array ($O(N)$), and the `current` path list ($O(N)$).
        
    - **$O(N \cdot N!)$** space required to store the $N!$ permutations of length $N$ in the `result` list.
