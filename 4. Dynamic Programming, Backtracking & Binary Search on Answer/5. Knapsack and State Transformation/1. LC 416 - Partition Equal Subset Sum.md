Question: https://leetcode.com/problems/partition-equal-subset-sum/description/

```cs
public class Solution
{
    public bool CanPartition(int[] nums)
    {
        // 1. Calculate total sum of array elements
        int total = nums.Sum();

        // 2. An odd sum cannot be divided into two equal integer subsets
        if (total % 2 != 0)
        {
            return false;
        }

        // 3. Target sum for each subset
        int target = total / 2;

        // dp[sum] tracks whether a subset sum equal to 'sum' is achievable
        bool[] dp = new bool[target + 1];

        // Base case: sum of 0 is always achievable (empty subset)
        dp[0] = true;

        // 4. Dynamic Programming (0/1 Knapsack variation)
        foreach (int num in nums)
        {
            // Iterate backwards to ensure each element is used at most once per subset
            for (int sum = target; sum >= num; sum--)
            {
                dp[sum] = dp[sum] || dp[sum - num];
            }
        }

        return dp[target];
    }
}
```

## Complexity Analysis

Let $n$ be the number of elements in `nums` (`nums.Length`), and $S = \frac{\text{sum}(\text{nums})}{2}$ be the target subset sum.

### Time Complexity: $\mathcal{O}(n \times S)$

- **Sum Calculation:** `nums.Sum()` iterates through the array once in $\mathcal{O}(n)$ time.
    
- **DP Loops:** The outer `foreach` loop runs $n$ times. For each element, the inner `for` loop executes at most $S - \text{num} + 1 \le S + 1$ times.
    
- **Total Time:** $\mathcal{O}(n) + \mathcal{O}(n \times S) = \mathcal{O}(n \times S)$ (pseudo-polynomial time complexity dependent on the subset target sum $S$).
    

### Space Complexity: $\mathcal{O}(S)$

- **DP Array:** The algorithm uses a 1D boolean dynamic programming array `dp` of size $S + 1$.
    
- **Auxiliary Space:** Only a few scalar variables (`total`, `target`, `num`, `sum`) are used in $\mathcal{O}(1)$ space.
    
- **Total Space:** $\mathcal{O}(S)$ auxiliary memory.
