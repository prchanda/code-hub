Question: https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/description/

Explanation : https://neetcode.io/solutions/capacity-to-ship-packages-within-d-days

```cs
public class Solution
{
    public int ShipWithinDays(int[] weights, int days)
    {
        int left = weights.Max();
        int right = weights.Sum();

        // Binary search to find the minimum feasible shipping capacity
        while (left <= right)
        {
            int capacity = left + (right - left) / 2;

            if (CanShip(weights, capacity, days))
            {
                // Current capacity works; try to find a smaller valid capacity
                right = capacity - 1;
            }
            else
            {
                // Current capacity is too small; increase capacity
                left = capacity + 1;
            }
        }

        return left;
    }

    private bool CanShip(int[] weights, int capacity, int days)
    {
        int currentLoad = 0;
        int daysUsed = 1;

        foreach (int weight in weights)
        {
            if (currentLoad + weight > capacity)
            {
                daysUsed++;
                currentLoad = 0;
            }

            currentLoad += weight;
        }

        return daysUsed <= days;
    }
}
```

## Complexity Analysis

Let $n$ be the number of packages in `weights` (`weights.Length`), $M = \max(\text{weights})$ be the maximum single item weight, and $S = \sum \text{weights}$ be the sum of all item weights.

### Time Complexity: $\mathcal{O}(n \log(S - M))$

- **Search Bounds Calculation:** Finding the maximum and sum of `weights` takes $\mathcal{O}(n)$ time.
    
- **Binary Search Range:** The search space spans from $M$ to $S$, requiring $\mathcal{O}(\log(S - M))$ iterations.
    
- **Feasibility Check (`CanShip`):** Each call iterates through all $n$ items in $\mathcal{O}(n)$ time.
    
- **Total Time:** $\mathcal{O}(n) + \mathcal{O}(n \log(S - M)) = \mathcal{O}(n \log(S - M))$.
    

### Space Complexity: $\mathcal{O}(1)$

- **Auxiliary Space:** The algorithm only uses a few primitive variables (`left`, `right`, `capacity`, `currentLoad`, `daysUsed`).
    
- **Total Space:** $\mathcal{O}(1)$ constant auxiliary memory.
