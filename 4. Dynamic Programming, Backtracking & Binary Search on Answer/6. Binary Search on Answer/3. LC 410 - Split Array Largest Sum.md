Question: https://leetcode.com/problems/split-array-largest-sum/description/

Explanation: https://www.youtube.com/watch?v=YUF3_eBdzsk

```cs
public class Solution 
{
    public int SplitArray(int[] nums, int k) 
    {
        int left = nums.Max();
        int right = nums.Sum();

        // Binary search to minimize the maximum subarray sum
        while (left < right)
        {
            int mid = left + (right - left) / 2;

            if (CanSplit(nums, mid, k))
            {
                // Target sum is feasible; try to achieve a smaller maximum sum
                right = mid;
            }
            else
            {
                // Target sum is too small; increase allowed maximum sum
                left = mid + 1;
            }
        }

        return left;
    }

    private bool CanSplit(int[] nums, int maxSum, int k)
    {
        int subArrays = 1;
        int currentSum = 0;

        foreach (int num in nums)
        {
            currentSum += num;

            // Greedily start a new subarray if adding 'num' exceeds 'maxSum'
            if (currentSum > maxSum)
            {
                subArrays++;
                currentSum = num;
            }            
        }

        return subArrays <= k;
    }
}
```

## Complexity Analysis

Let $n$ be the number of elements in `nums` (`nums.Length`), $M = \max(\text{nums})$ be the maximum single element, and $S = \sum \text{nums}$ be the sum of all elements.

### Time Complexity: $\mathcal{O}(n \log(S - M))$

- **Initial Bounds Calculation:** `nums.Max()` and `nums.Sum()` evaluate the array in $\mathcal{O}(n)$ time.
    
- **Binary Search Range:** The search space spans from $M$ to $S$, requiring $\mathcal{O}(\log(S - M))$ iterations.
    
- **Feasibility Check (`CanSplit`):** Each check iterates through all $n$ elements greedily in $\mathcal{O}(n)$ time.
    
- **Total Time:** $\mathcal{O}(n) + \mathcal{O}(n \log(S - M)) = \mathcal{O}(n \log(S - M))$.
    

### Space Complexity: $\mathcal{O}(1)$

- **Auxiliary Space:** Memory usage is restricted to scalar variables (`left`, `right`, `mid`, `subArrays`, `currentSum`).
    
- **Total Space:** $\mathcal{O}(1)$ constant auxiliary memory.
