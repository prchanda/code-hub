Question: https://leetcode.com/problems/koko-eating-bananas/description/
Explanation : https://www.youtube.com/watch?v=U2SozAs9RzA

```cs
public class Solution
{
    public int MinEatingSpeed(int[] piles, int h)
    {
        int left = 1;
        int right = piles.Max();

        // Binary search to find the minimum feasible eating speed (k)
        while (left <= right)
        {
            int mid = left + (right - left) / 2;
            long hours = 0;

            // Calculate total hours required to finish all piles at speed 'mid'
            foreach (int pile in piles)
            {
                hours += (int)Math.Ceiling((double)pile / mid);
            }

            // If Koko can finish within 'h' hours, attempt to reduce eating speed
            if (hours <= h)
            {
                right = mid - 1;
            }
            else
            {
                left = mid + 1;
            }
        }

        return left;
    }
}
```


### Time Complexity: $\mathcal{O}(n \log M)$

- **Max Element Search:** `piles.Max()` scans the array once in $\mathcal{O}(n)$ time.
    
- **Binary Search Range:** The search space spans from $1$ to $M$, yielding $\mathcal{O}(\log M)$ iterations.
    
- **Feasibility Check:** Inside each iteration, the `foreach` loop evaluates all $n$ elements in $\mathcal{O}(n)$ time.
    
- **Total Time:** $\mathcal{O}(n) + \mathcal{O}(n \log M) = \mathcal{O}(n \log M)$.
    

### Space Complexity: $\mathcal{O}(1)$

- **Auxiliary Space:** Only scalar variables (`left`, `right`, `mid`, `hours`, `pile`) are declared.
    
- **Total Space:** $\mathcal{O}(1)$ constant auxiliary memory.
