Question: https://leetcode.com/problems/minimum-path-sum/

Explanation : https://www.youtube.com/watch?v=pGMsrvt0fpk 

```cs
using System;

public class Solution 
{
    public int MinPathSum(int[][] grid) 
    {
        int rows = grid.Length;
        int cols = grid[0].Length;

        int[,] dp = new int[rows + 1, cols + 1];

        // Base case helper: allows dp[rows - 1, cols - 1] to initialize properly
        dp[rows, cols - 1] = 0;

        // Initialize right boundary out-of-bounds cells to int.MaxValue
        for (int row = 0; row <= rows; row++)
        {
            dp[row, cols] = int.MaxValue;
        }

        // Initialize bottom boundary out-of-bounds cells to int.MaxValue
        for (int col = cols - 2; col >= 0; col--)
        {
            dp[rows, col] = int.MaxValue;
        }

        // Bottom-up Dynamic Programming
        for (int row = rows - 1; row >= 0; row--)
        {
            for (int col = cols - 1; col >= 0; col--)
            {
                dp[row, col] = grid[row][col] + Math.Min(dp[row + 1, col], dp[row, col + 1]);
            }
        }

        return dp[0, 0];
    }
}
```


### Complexity Analysis

Let $m$ be the number of rows (`rows`) and $n$ be the number of columns (`cols`).

- **Time Complexity:** $\mathcal{O}(m \times n)$
    
    - Setting up the outer boundary padding takes $\mathcal{O}(m + n)$ operations.
        
    - The nested loops process each cell in the $m \times n$ grid exactly once, performing constant-time $\mathcal{O}(1)$ additions and comparison operations per cell.
        
- **Space Complexity:** $\mathcal{O}(m \times n)$
    
    - Allocates a 2D DP array of size $(m + 1) \times (n + 1)$ to store subproblem answers.
        

> **Tip:** You can optimize the space complexity down to **$\mathcal{O}(n)$** by storing only 1 row of state transitions, or even **$\mathcal{O}(1)$** auxiliary space by computing the minimum path sums directly in-place within the input `grid` matrix.
