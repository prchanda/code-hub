Question : https://leetcode.com/problems/dungeon-game/description/

`dp[row, col]` = minimum HP you must have when ENTERING this cell so that you can eventually reach the princess alive.

```cs
public class Solution 
{
    public int CalculateMinimumHP(int[][] dungeon) 
    {
        int rows = dungeon.Length;
        int cols = dungeon[0].Length;

        int[,] dp = new int[rows + 1, cols + 1];
        int infinity = int.MaxValue / 2;

        // Fill boundary walls with infinity to avoid out-of-bound errors
        for (int row = 0; row <= rows; row++) 
        {
            dp[row, cols] = infinity;
        }

        for (int col = 0; col < cols; col++) 
        {
            dp[rows, col] = infinity;
        }

        // Base case: target destination requires at least 1 HP upon exit
        dp[rows, cols - 1] = 1;

        // Bottom-up dynamic programming traversal from bottom-right to top-left
        for (int row = rows - 1; row >= 0; row--) 
        {
            for (int col = cols - 1; col >= 0; col--) 
            {
                int minimumEnergy = Math.Min(dp[row + 1, col], dp[row, col + 1]);
                // HP I need BEFORE this cell = HP I need AFTER this cell - HP this cell gives me
                dp[row, col] = Math.Max(1, minimumEnergy - dungeon[row][col]);
            }
        }

        return dp[0, 0];
    }
}

```


## Complexity Analysis

Let $m$ be the number of rows (`rows`) and $n$ be the number of columns (`cols`) in the grid.

### Time Complexity: $\mathcal{O}(m \times n)$

- **Boundary Initialization:** Initializing the DP matrix boundaries takes $\mathcal{O}(m + n)$ iterations.
    
- **Nested DP Loop:** The main logic consists of two nested loops running $m$ and $n$ times respectively. Each cell calculation performs $\mathcal{O}(1)$ basic arithmetic and comparison operations (`Math.Min` and `Math.Max`).
    
- **Total Time:** $\mathcal{O}(m + n) + \mathcal{O}(m \times n) = \mathcal{O}(m \times n)$.
    

### Space Complexity: $\mathcal{O}(m \times n)$

- **DP Matrix:** The algorithm allocates a 2D array `dp` of size $(m + 1) \times (n + 1)$, which uses space proportional to the total number of cells.
    
- **Space Optimization Note:** Space can be optimized to $\mathcal{O}(n)$ by using a 1D DP array of size $n + 1$, as state transitions for any given row only depend on values from the current and subsequent row/column.
