Question: https://leetcode.com/problems/decode-ways/

Explanation : https://www.youtube.com/watch?v=6aEyTjOwlJU

```cs 
/* Recursive solution: At every index, we have two choices
   At every index, we have two choices. Suppose we're at:
   
   226
   ^
   index = 0
   
   Choice 1: Take one digit, Then we need to solve: Decode(1)
   2 | 26
   
   Choice 2: Take two digits, Then we need to solve: Decode(3)
   22 | 6   
   
   Therefore: Decode(0) = Decode(1) + Decode(2)

*/
public class Solution
{
    public int NumDecodings(string s)
    {
        return Decode(s, 0);
    }

    private int Decode(string s, int index)
    {
        // Successfully decoded the entire string
        if (index == s.Length)
        {
            return 1;
        }

        // '0' cannot be decoded by itself
        if (s[index] == '0')
        {
            return 0;
        }

        // Choice 1: take one digit
        int ways = Decode(s, index + 1);

        // Choice 2: take two digits
        if (index + 1 < s.Length)
        {
            int number = (s[index] - '0') * 10
                       + (s[index + 1] - '0');

            if (number >= 10 && number <= 26)
            {
                ways += Decode(s, index + 2);
            }
        }

        return ways;
    }
}
```

```                    Decode(0)
              Decode(1)      Decode(2)
              /       \           |
         Decode(2)  Decode(3)  Decode(3)
           /           |          |
      Decode(3)       1          1
         |
         1
```


# Top-Down approach / Memoization

```cs
public class Solution
{
    public int NumDecodings(string s)
    {
        int[] dp = new int[s.Length + 1];
        Array.Fill(dp, -1);

        return Decode(s, 0, dp);
    }

    private int Decode(string s, int index, int[] dp)
    {
        if (index == s.Length)
        {
            return 1;
        }

        if (s[index] == '0')
        {
            return 0;
        }

        if (dp[index] != -1)
        {
            return dp[index];
        }

        // Take one digit
        int ways = Decode(s, index + 1, dp);

        // Take two digits
        if (index + 1 < s.Length)
        {
            int number = (s[index] - '0') * 10
                       + (s[index + 1] - '0');

            if (number >= 10 && number <= 26)
            {
                ways += Decode(s, index + 2, dp);
            }
        }

        return dp[index] = ways;
    }
}
```


# Bottom-up approach

```cs
public class Solution
{
    public int NumDecodings(string s)
    {
        int n = s.Length;
        int[] dp = new int[n + 1];

        // Empty string has one valid decoding
        dp[n] = 1;

        for (int i = n - 1; i >= 0; i--)
        {
            // '0' cannot be decoded by itself
            if (s[i] == '0')
            {
                dp[i] = 0;
                continue;
            }

            // Take one digit
            dp[i] = dp[i + 1];

            // Take two digits
            if (i + 1 < n)
            {
                int number = (s[i] - '0') * 10
                           + (s[i + 1] - '0');

                if (number >= 10 && number <= 26)
                {
                    dp[i] += dp[i + 2];
                }
            }
        }

        return dp[0];
    }
}
```

### Time Complexity: $O(N)$

- **Single Loop:** Iterates $N$ times (from index $1$ to $N$).
    
- **Constant Operations:**
    
    - Character indexing `s[index - 1]` takes $O(1)$ time.
        
    - `s.Substring(index - 2, 2)` extracts a fixed length of 2 characters in $O(1)$ time.
        
    - `int.Parse(...)` parses a 2-digit string in $O(1)$ time.
        
- **Total Time Complexity:** $\mathbf{O(N)}$ linear time.
    

### Space Complexity: $O(N)$

- **`dp` Array:** Requires size $N + 1$ to hold the subproblem state values $\rightarrow \mathbf{O(N)}$ auxiliary space.

### 💡 Quick Performance Optimizations

1. **Avoid Substring Allocations:** Creating a new string slice in every iteration causes memory allocations. You can replace `int.Parse(s.Substring(...))` with direct character arithmetic:
    
    C#
    
    ```
    int lastTwoDigits = (s[index - 2] - '0') * 10 + (s[index - 1] - '0');
    ```
    
1. **Optimize Space to $O(1)$:** Since `dp[index]` only relies on `dp[index - 1]` and `dp[index - 2]`, you can replace the entire array with two variables (`prev1` and `prev2`), dropping space complexity down to **$O(1)$**.

```cs
public class Solution
{
    public int NumDecodings(string s)
    {
        int n = s.Length;

        // dp[i + 1]
        int oneStep = 1;

        // dp[i + 2]
        int twoStep = 0;

        for (int i = n - 1; i >= 0; i--)
        {
            int current;

            if (s[i] == '0')
            {
                current = 0;
            }
            else
            {
                // Take one digit
                current = oneStep;

                // Take two digits
                if (i + 1 < n)
                {
                    int number = (s[i] - '0') * 10
                               + (s[i + 1] - '0');

                    if (number >= 10 && number <= 26)
                    {
                        current += twoStep;
                    }
                }
            }

            // Move the window
            twoStep = oneStep;
            oneStep = current;
        }

        return oneStep;
    }
}
```
