Question : https://leetcode.com/problems/delete-and-earn/

Explanation: https://www.youtube.com/watch?v=7FCemBxvGw0

```cs
public class Solution
{
    public int DeleteAndEarn(int[] nums)
    {
        int max = nums.Max();
        int[] dp = new int[max + 1];

        foreach (int num in nums)
        {
            dp[num] += num;
        }

        int prev1 = 0;
        int prev2 = 0;

        foreach (int num in dp)
        {
            int current = Math.Max(prev1, prev2 + num);
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
```

## Complexity Analysis

Let $N$ be the **number of elements in `nums`** (`nums.Length`) and $M$ be the **maximum value present in `nums`** (`nums.Max()`).

### Time Complexity: $O(N + M)$

- **Finding Maximum (`nums.Max()`):** Iterates through `nums` once $\rightarrow O(N)$.
    
- **Populating Frequency Sum (`dp` array):** Iterates through `nums` once $\rightarrow O(N)$.
    
- **House Robber DP Loop:** Iterates through `dp` array of size $M + 1$ $\rightarrow O(M)$.
    
- **Total Time Complexity:** $O(N) + O(N) + O(M) = \mathbf{O(N + M)}$.
    

### Space Complexity: $O(M)$

- **`dp` Array Allocation:** The array size depends on the maximum value $M$ in `nums` (`new int[max + 1]`), consuming $O(M)$ space.
    
- **Variables:** `prev1`, `prev2`, and `current` take $O(1)$ constant space.
    
- **Total Auxiliary Space Complexity:** $\mathbf{O(M)}$.
    

> **Note on Performance:** If $M$ (the maximum value) is extremely large compared to $N$ (e.g., `nums = [1, 1000000000]`), the space allocation for `dp` will be large. In such cases, replacing the `dp` array with a `Dictionary<int, int>` sorted by key reduces the space complexity down to $O(N)$ space and $O(N \log N)$ time.


```cs 
// Dictionary solution to avoid unnecessary space wastage due to DP array

public class Solution
{
    public int DeleteAndEarn(int[] nums)
    {
        SortedDictionary<int, int> points = new();

        foreach (int num in nums)
        {
            points[num] = points.GetValueOrDefault(num) + num;
        }

        int bestTwoValuesBack = 0;
        int bestOneValueBack = 0;
        int lastValue = 0; // value starts from 1 as per constraint, hence taken as 0

        foreach (var (value, currentPoints) in points)
        {
            int currentBest;

            if (value == lastValue + 1)
            {
                // Adjacent values conflict
                currentBest = Math.Max(
                    bestOneValueBack,
                    bestTwoValuesBack + currentPoints
                );
            }
            else
            {
                // Gap present (e.g., [2,2,4,4]). 2 and 4 do not conflict.
                currentBest = bestOneValueBack + currentPoints;
            }

            bestTwoValuesBack = bestOneValueBack;
            bestOneValueBack = currentBest;
            lastValue = value;
        }

        return bestOneValueBack;
    }
}
```


```
First aggregate all occurrences of each number into `points[value] = value × frequency`, because taking a value means taking all its copies. Then process the values in sorted order using the same idea as **House Robber**: if the current value is consecutive to the previous value (`value == lastValue + 1`), we have a conflict, so choose `max(bestOneValueBack, bestTwoValuesBack + currentPoints)`; otherwise there is a gap, meaning the current value does not conflict with the previous one, so simply take `bestOneValueBack + currentPoints`. We only keep the best result for the previous value and the value before it (`bestOneValueBack`, `bestTwoValuesBack`), giving **O(n log n)** time due to sorting the distinct values and **O(n)** space for the dictionary. **Key memory hook: Delete & Earn → aggregate points by value → sorted values → House Robber, with gaps removing the adjacency conflict.
```
