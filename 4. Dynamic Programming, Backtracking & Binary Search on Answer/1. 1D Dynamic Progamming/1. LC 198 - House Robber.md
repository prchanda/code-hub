### Recursive solution

```cs
public class Solution 
{
    public int Rob(int[] nums) 
    {
        return Calculate(0, nums);
    }

    private int Calculate(int index, int[] nums)
    {
        if (index >= nums.Length)
        {
            return 0;
        }

        int rob = nums[index] + Calculate(index + 2, nums);
        int skip = Calculate(index + 1, nums);

        return Math.Max(rob, skip);
    }
}
```


### Top-Down approach

```cs
public class Solution 
{
    public int Rob(int[] nums) 
    {
        int[] cache = new int[nums.Length];
        Array.Fill(cache, -1);
        return Calculate(0, nums, cache);
    }

    private int Calculate(int index, int[] nums, int[] cache)
    {
        if (index >= nums.Length)
        {
            return 0;
        }
        
        if (cache[index] != -1)
        {
            return cache[index];
        }

        int rob = nums[index] + Calculate(index + 2, nums, cache);
        int skip = Calculate(index + 1, nums, cache);

        return cache[index] = Math.Max(rob, skip);
    }
}
```


### Bottom-up approach

```cs
public class Solution 
{
    public int Rob(int[] nums) 
    {        
        int currentState = 0;
        int nextOneState = 0;
        int nextTwoState = 0;
        
        for (int index = nums.Length - 1; index >= 0; index--)
        {
            currentState = Math.Max(nums[index] + nextTwoState, nextOneState);            
            nextTwoState = nextOneState;
            nextOneState = currentState;
        }

        return currentState;
    }
}
```

```cs
public class Solution
{
    public int Rob(int[] nums)
    {
        int prev1 = 0;
        int prev2 = 0;

        foreach (int num in nums)
        {
            int current = Math.Max(prev1, prev2 + num);
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}
```

| **Feature**         | **Your First Version (Backward)**                                                             | **Your Second Version (Forward)**                                                                 |
| ------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Direction**       | Right $\rightarrow$ Left (`nums.Length - 1` down to `0`)                                      | Left $\rightarrow$ Right (`foreach` through `nums`)                                               |
| **Mental Model**    | "If I am standing at house $i$, what is the max loot I can get looking _forward_ to the end?" | "If I have visited houses up to $i$, what is the max loot I have accumulated looking _backward_?" |
| **Both Bottom-Up?** | Yes                                                                                           | Yes                                                                                               |


## Complexity Analysis

Let $N$ be the number of elements in the `nums` array.

### Time Complexity: $O(N)$

- The algorithm iterates through the `nums` array **once** using a single `foreach` loop.
    
- Inside the loop, all arithmetic operations, variable assignments, and `Math.Max` calls take $O(1)$ constant time.
    
- Total time spent is strictly linear with respect to the input size: $O(N)$.
    

### Space Complexity: $O(1)$

- Instead of allocating an $O(N)$ dynamic programming table (`dp[]`), the state is tracked using only two integer variables (`prev1` and `prev2`) and a temporary loop variable (`current`).
    
- The space required remains constant regardless of how large `nums` grows: $O(1)$ auxiliary space.
