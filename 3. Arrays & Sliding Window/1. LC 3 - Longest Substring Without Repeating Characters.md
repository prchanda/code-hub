Question: https://leetcode.com/problems/longest-substring-without-repeating-characters/

```cs
public class Solution
{
    public int LengthOfLongestSubstring(string s)
    {
        Dictionary<char, int> lookup = new Dictionary<char, int>();

        int startIndex = 0;
        int length = 0;

        for (int index = 0; index < s.Length; index++)
        {
            if (lookup.ContainsKey(s[index]))
            {
                int prevIndex = lookup[s[index]];

                startIndex = Math.Max(startIndex, prevIndex + 1);                
            }
            
            lookup[s[index]] = index;

            length = Math.Max(length, index - startIndex + 1);
        }

        return length;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$, where $N$ is the length of the string. The algorithm traverses the string once with a sliding window, and dictionary lookups/updates take $\mathcal{O}(1)$ average time.
    
- **Space Complexity:** $\mathcal{O}(\min(N, M))$, where $N$ is the length of the string and $M$ is the size of the character set (e.g., 26 for lowercase English letters, or up to 128/256 for ASCII/Unicode). In the worst-case scenario with all unique characters, the dictionary stores up to $N$ entries.
