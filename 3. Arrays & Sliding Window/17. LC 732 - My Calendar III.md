Question: https://leetcode.com/problems/my-calendar-iii/description/

```cs
public class MyCalendarThree
{
    private SortedDictionary<int, int> events;

    public MyCalendarThree()
    {
        events = new SortedDictionary<int, int>();
    }

    public int Book(int startTime, int endTime)
    {        
        // Because at start, a booking becomes active:
        events[startTime] = events.GetValueOrDefault(startTime) + 1;
        // At end, it stops being active:
        events[endTime] = events.GetValueOrDefault(endTime) - 1;

        int count = 0;  // How many bookings are currently active?
        int maxInt = 0; // What is the maximum number of simultaneous bookings we've seen?

        foreach (var pair in events)
        {
            count += pair.Value;
            maxInt = Math.Max(maxInt, count);
        }

        return maxInt;
    }
}
```

- **Time Complexity:** $O(N)$ per `Book` call, where $N$ is the number of distinct event entries in the dictionary, because it traverses the entire `SortedDictionary` linearly to calculate the active count. For $N$ total calls, the cumulative worst-case time complexity is $O(N^2)$.
    
- **Space Complexity:** $O(N)$ to store the start and end event coordinates in the `SortedDictionary`.
