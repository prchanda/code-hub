### Problem Statement

You are given a 0-indexed 2D integer array `peaks` where `peaks[i] = [xi, yi]` states that mountain $i$ has a peak at coordinates $(x_i, y_i)$.

A mountain can be described as a right-angled isosceles triangle, with its base along the $x$-axis and a right angle at its peak. More formally, the gradients of ascending and descending the mountain are $1$ and $-1$ respectively.

A mountain is considered visible if its peak does not lie within another mountain (including the border of other mountains).

Return the number of visible mountains.

### Constraints

- $1 \le peaks.length \le 10^5$
    
- $peaks[i].length == 2$
    
- $1 \le x_i, y_i \le 10^5$

```cs
public class Solution 
{
    public int VisibleMountains(int[][] peaks) 
    {
        int n = peaks.Length;
        var mountains = new (int left, int right)[n];

        for (int i = 0; i < n; i++) 
        {
            int x = peaks[i][0];
            int y = peaks[i][1];
            mountains[i] = (x - y, x + y);
        }

        // Sort by:
        // 1. left ascending
        // 2. right descending
        /* When you sort by left ascending and right descending, two mountains that start at the same left position get ordered with the bigger one first. 
	       That way, when you sweep left to right, your `maxRight` value always represents the furthest reach we've seen so far without missing a bigger umbrella 
	       mountain that should cover the smaller ones. If we sorted right ascending instead, we'd have to do extra checks and handle equal left cases more carefully,
	       which complicates the scan.
	    */
        Array.Sort(mountains, (a, b) => 
        {
            if (a.left != b.left)
                return a.left.CompareTo(b.left);

            return b.right.CompareTo(a.right);
        });

        int visible = 0;
        int maxRight = int.MinValue;

        for (int i = 0; i < n; i++) 
        {
            int left = mountains[i].left;
            int right = mountains[i].right;

            // Completely covered by a previous mountain
            if (right <= maxRight)
                continue;

            maxRight = right;

            // So if two mountains are exact duplicates, each one is completely covered by the other. That's why the correct count is zero visible mountains
            if (i + 1 < n && 
                mountains[i + 1].left == left && 
                mountains[i + 1].right == right) 
            {
                continue;
            }

            visible++;
        }

        return visible;
    }
}
```
