Question: https://leetcode.com/problems/search-in-rotated-sorted-array/description/

```cs
public class Solution 
{
    public int Search(int[] nums, int target) 
    {
        // Initialize two pointers for the search boundaries
        int left = 0, right = nums.Length - 1;

        // Perform modified binary search
        while (left <= right)
        {
            // Calculate the middle index safely to prevent integer overflow
            int mid = left + (right - left) / 2;

            // Check if the target is found at the middle index
            if (nums[mid] == target)
                return mid;

            // Determine which half of the array is normally sorted
            if (nums[left] <= nums[mid])
            {
                // Left half is sorted; check if the target lies within this sorted range
                if (nums[left] <= target && target < nums[mid])
                    right = mid - 1; // Search left
                else
                    left = mid + 1;  // Search right
            }
            else
            {
                // Right half is sorted; check if the target lies within this sorted range
                if (target > nums[mid] && target <= nums[right])
                    left = mid + 1;  // Search right
                else
                    right = mid - 1; // Search left
            }
        }

        // Target not found in the array
        return -1;
    }
}
```

Time complexity is $O(\log n)$ and space complexity is $O(1)$.
