
### Problem Statement

We are given a list `schedule` of employees, where each employee's schedule is represented by a list of non-overlapping intervals sorted by start time.

Return the list of finite intervals representing common, positive-length free time for all employees, also in sorted order.

### Examples

**Example 1:**

- **Input:** `schedule = [[[1,2],[5,6]],[[1,3]],[[4,10]]]`
    
- **Output:** `[[3,4]]`
    
- **Explanation:** There are a total of three employees, and all common free time intervals would be `[-inf, 1], [3, 4], [10, inf]`. We discard any intervals that contain infinity as they aren't finite.
    

**Example 2:**

- **Input:** `schedule = [[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]`
    
- **Output:** `[[5,6],[7,9]]`
    

### Constraints

- `1 <= schedule.length, schedule[i].length <= 50`
    
- `0 <= schedule[i].start < schedule[i].end <= 10^8`

```cs

public class Solution 
{
    public IList<Interval> EmployeeFreeTime(IList<IList<Interval>> schedule) 
    {
        List<Interval> allIntervals = new List<Interval>();

        // Step 1: Flatten all individual employee schedules into a single list
        foreach (var employee in schedule) 
        {
            foreach (var interval in employee) 
            {
                allIntervals.Add(interval);
            }
        }

        // Step 2: Sort the intervals by their start time
        allIntervals.Sort((a, b) => a.start.CompareTo(b.start));

        List<Interval> freeTime = new List<Interval>();
        if (allIntervals.Count == 0) 
	        return freeTime;

        int prevEnd = allIntervals[0].end;

        // Step 3: Iterate through the sorted intervals to find gaps
        for (int i = 1; i < allIntervals.Count; i++) 
        {
            Interval current = allIntervals[i];

            // If the current interval starts after the previous end time, we found a gap
            if (current.start > prevEnd) 
            {
                freeTime.Add(new Interval(prevEnd, current.start));
                prevEnd = current.end;
            } 
            else 
            {
                // Otherwise, merge/extend the current working end time
                prevEnd = Math.Max(prevEnd, current.end);
            }
        }

        return freeTime;
    }
}
```


### Complexity

- **Time Complexity:** $\mathcal{O}(N \log N)$ where $N$ is the total number of intervals across all employees. Flattening takes $\mathcal{O}(N)$, sorting takes $\mathcal{O}(N \log N)$, and the final sweep takes linear $\mathcal{O}(N)$ time.
    
- **Space Complexity:** $\mathcal{O}(N)$ to store the flattened list of intervals and the resulting free time list.
