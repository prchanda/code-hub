Question: https://leetcode.com/problems/car-pooling/description/

`This sweep-line algorithm represents the optimal approach for handling arbitrary or sparse location coordinates.`

```cs
public class Solution 
{
    public bool CarPooling(int[][] trips, int capacity) 
    {
        SortedDictionary<int, int> events = new SortedDictionary<int, int>();

        foreach (var trip in trips)
        {
            events[trip[1]] = events.GetValueOrDefault(trip[1]) + trip[0];
            events[trip[2]] = events.GetValueOrDefault(trip[2]) - trip[0];            
        }

        int passengers = 0;
        foreach (var evt in events)
        {
            passengers += evt.Value;
            if (passengers > capacity)
                return false;
        }

        return true;
    }
}
```

- **Time Complexity:** $O(N \log N)$ where $N$ is the number of trips, due to inserting and maintaining sorted keys in the `SortedDictionary` red-black tree, followed by an $O(U)$ linear scan over the unique event locations (where $U \le 2N$).
    
- **Space Complexity:** $O(N)$ to store the delta events in the dictionary.
