Question: https://leetcode.com/problems/validate-stack-sequences/description/

Explanation: https://www.youtube.com/watch?v=mzua0r94kb8

```cs
public class Solution 
{
    public bool ValidateStackSequences(int[] pushed, int[] popped) 
    {
        Stack<int> stack = new Stack<int>();
        int index = 0;
        
        foreach (var num in pushed)
        {
            stack.Push(num);
            
            while (index < popped.Length && stack.Count > 0 && popped[index] == stack.Peek())
            {
                stack.Pop();
                index++;
            }
        }

        return stack.Count == 0;
    }
}
```


### Complexity

- **Time Complexity:** $\mathcal{O}(n)$ — Every element is pushed onto the stack exactly once and popped at most once, meaning the loops run in linear time relative to the number of elements $n$. 
      
- **Space Complexity:** $\mathcal{O}(n)$ — In the worst-case scenario, all elements are pushed onto the stack before any are popped, requiring linear extra space.
