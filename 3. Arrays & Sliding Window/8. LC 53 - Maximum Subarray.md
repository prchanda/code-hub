Question: https://leetcode.com/problems/maximum-subarray/

Explanation: https://www.youtube.com/watch?v=5WZl3MMT0Eg

```cs
public class Solution {
    public int MaxSubArray(int[] nums) {
        int maxSum = nums[0], currentSum = 0;

        foreach(int num in nums)
        {
            if(currentSum < 0)
                currentSum = 0;
            currentSum += num;
            maxSum = Math.Max(maxSum, currentSum);
        }

        return maxSum;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$, where $N$ is the number of elements in the `nums` array. The algorithm performs a single pass through the array using Kadane's algorithm.
    
- **Space Complexity:** $\mathcal{O}(1)$ auxiliary space, as it only uses a couple of variables to keep track of the current and maximum sums.
