Question: https://leetcode.com/problems/product-of-array-except-self/


```cs
public class Solution {
    public int[] ProductExceptSelf(int[] nums) {
        int leftRunningProduct = 1, rightRunningProduct = 1;
        int[] output = new int[nums.Length];

        for(int index = 0; index < nums.Length; index++)
        {
            output[index] = leftRunningProduct;
            leftRunningProduct = nums[index] * leftRunningProduct;
        }

        for(int index = nums.Length - 1; index >= 0; index--)
        {
            output[index] = output[index] * rightRunningProduct;
            rightRunningProduct = nums[index] * rightRunningProduct;
        }

        return output;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$, where $N$ is the number of elements in the `nums` array. The algorithm uses two independent linear passes (one forward, one backward) to compute the prefix and suffix products, performing a constant number of operations per element.
    
- **Space Complexity:** $\mathcal{O}(1)$ auxiliary space, excluding the space needed for the output array (as per LeetCode's standard space complexity evaluation for this problem, where the return array is not counted towards extra space).
