Question: https://leetcode.com/problems/subarray-sum-equals-k/description/

```cs
public class Solution {
    public int SubarraySum(int[] nums, int k) {
        Dictionary<int, int> prefixSumLookup = new Dictionary<int, int>(){{0, 1}};
        int prefixSum = 0, count = 0;
        
        for(int index = 0; index < nums.Length; index++)
        {
            prefixSum += nums[index];
            if(prefixSumLookup.TryGetValue(prefixSum - k, out int frequency))
            {
                count += frequency;
            }
            prefixSumLookup[prefixSum] = prefixSumLookup.GetValueOrDefault(prefixSum) + 1;
        }
        
        return count;
    }   
}
```


### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$, where $N$ is the number of elements in the array. The algorithm traverses the array once, performing constant-time $\mathcal{O}(1)$ average insertions and lookups in the hash dictionary.
    
- **Space Complexity:** $\mathcal{O}(N)$ in the worst case, as the dictionary stores unique running prefix sums and their frequencies up to the length of the array.
