Question: https://leetcode.com/problems/binary-tree-cameras/description/

```cs
public enum CameraState
{
    NeedCamera = 0,
    HaveCamera,
    GotCoverage
}

public class Solution 
{
    public int MinCameraCover(TreeNode root) 
    {
        int cameraCount = 0;

        // If root itself needs coverage after DFS traversal, place a camera at root
        if (DFS(root, ref cameraCount) == CameraState.NeedCamera)
            cameraCount++;

        return cameraCount;
    }

    private CameraState DFS(TreeNode node, ref int cameraCount)
    {
        // Null nodes are treated as covered so leaves don't needlessly place cameras
        if (node == null)
            return CameraState.GotCoverage;

        CameraState left = DFS(node.left, ref cameraCount);
        CameraState right = DFS(node.right, ref cameraCount);

        // 1. If any child needs coverage, current node MUST place a camera
        if (left == CameraState.NeedCamera || right == CameraState.NeedCamera)
        {
            cameraCount++;
            return CameraState.HaveCamera;
        }

        // 2. If any child has a camera, current node is covered
        if (left == CameraState.HaveCamera || right == CameraState.HaveCamera)
        {
            return CameraState.GotCoverage;
        }

        // 3. If both children are covered but have no camera, current node needs coverage
        return CameraState.NeedCamera;
    }
}
```

### Complexity Analysis

Let $N$ be the total number of nodes in the binary tree and $H$ be the height of the tree.

- **Time Complexity:** $\mathcal{O}(N)$
    
    - The bottom-up post-order DFS traversal visits every node in the binary tree exactly once.
        
    - At each node, state evaluations and decision logic run in $\mathcal{O}(1)$ constant time.
        
    - Total time is linear with respect to the number of nodes: $\mathcal{O}(N)$.
        
- **Space Complexity:** $\mathcal{O}(H)$
    
    - **Call Stack Space:** The algorithm uses implicit stack memory due to recursion up to height $H$.
        
        - **Average / Balanced Tree:** $\mathcal{O}(\log N)$ stack space.
            
        - **Worst Case (Skewed Tree):** $\mathcal{O}(N)$ stack space if the tree degenerates into a linear chain.
            
    - **Auxiliary Memory:** $\mathcal{O}(1)$ beyond the recursion call stack.



A leaf shouldn't immediately install a camera on itself. Instead, it tells its parent:

> **"I'm not covered; you need to deal with me."**

So our state convention can be:

0 = needs camera
1 = has camera
2 = covered

**If either child needs a camera:**

```
child == 0
      ↓
put camera here
      ↓
return 1
```

**Otherwise, if either child has a camera:**

```
child == 1
      ↓
I'm covered
      ↓
return 2
```


**Otherwise:**

```
children are covered
      ↓
I don't have a camera
      ↓
I need my parent to cover me
      ↓
return 0
```

### What about the root?

If the root itself returns `0`, it has no parent to cover it. So we put a camera at the root.
