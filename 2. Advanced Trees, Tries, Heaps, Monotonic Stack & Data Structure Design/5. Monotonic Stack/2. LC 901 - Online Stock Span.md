Question: https://leetcode.com/problems/online-stock-span/description/

Explanation: https://www.youtube.com/watch?v=slYh0ZNEqSw

```cs
public class StockSpanner
{
    private Stack<(int price, int span)> stack;

    public StockSpanner()
    {
        stack = new Stack<(int price, int span)>();
    }

    public int Next(int price)
    {
        int span = 1;

        while (stack.Count > 0 && stack.Peek().price <= price)
        {
            var previous = stack.Pop();
            span += previous.span;
        }

        stack.Push((price, span));

        return span;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $O(1)$ amortized per `Next` call ($O(n)$ overall for $n$ calls)
    
    - Each price is pushed onto the stack exactly once and popped at most once. Over a sequence of $n$ calls to `Next`, the total number of `push` and `pop` operations is bounded by $2n$, yielding an amortized time complexity of $O(1)$ per call.
        
- **Space Complexity:** $O(n)$
    
    - In the worst-case scenario (e.g., when prices are strictly increasing), every price and its corresponding span will be stored in the stack, requiring linear space relative to the number of `Next` calls.
