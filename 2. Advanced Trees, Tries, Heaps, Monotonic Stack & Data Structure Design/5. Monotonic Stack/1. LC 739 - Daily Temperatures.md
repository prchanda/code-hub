Question: https://leetcode.com/problems/daily-temperatures/

Explanation: https://www.youtube.com/watch?v=cTBiBSnjO3c


```cs
public class Solution
{
    public int[] DailyTemperatures(int[] temperatures)
    {
        Stack<int> stack = new Stack<int>();
        int[] answer = new int[temperatures.Length];

        for (int index = 0; index < temperatures.Length; index++)
        {
            while (stack.Count > 0 && temperatures[stack.Peek()] < temperatures[index])
            {
                int previousIndex = stack.Pop();
                answer[previousIndex] = index - previousIndex;
            }
            stack.Push(index);
        }

        return answer;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $O(n)$
    
    - Although there is a `while` loop inside a `for` loop, each index is pushed onto and popped from the stack at most once. Therefore, the inner loop runs a total of at most $n$ times across the entire execution, making the overall time linear with respect to the length of the array ($n$).
        
- **Space Complexity:** $O(n)$
    
    - The `answer` array takes $O(n)$ space. In the worst-case scenario (e.g., a strictly descending array of temperatures), every index will be pushed onto the `stack`, requiring an additional $O(n)$ space.
