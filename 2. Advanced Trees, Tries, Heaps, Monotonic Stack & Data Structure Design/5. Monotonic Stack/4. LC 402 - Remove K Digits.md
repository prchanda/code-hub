Question: https://leetcode.com/problems/remove-k-digits/description/

Explanation: https://www.youtube.com/watch?v=cFabMOnJaq0

```cs
public class Solution 
{
    public string RemoveKdigits(string num, int k) 
    {
        if (num.Length == k) return "0";

        StringBuilder sb = new StringBuilder();

        foreach (char c in num) 
        {
            // Maintain a monotonic increasing sequence by removing larger digits preceding a smaller digit
            while (sb.Length > 0 && k > 0 && sb[sb.Length - 1] > c) 
            {
                sb.Length--; // Pop from the pseudo-stack
                k--;
            }
            sb.Append(c);
        }

        // If k is still greater than 0, remove from the end (since remaining digits are sorted ascending)
        while (k > 0 && sb.Length > 0) 
        {
            sb.Length--;
            k--;
        }

        // Find the first non-zero index to handle leading zeros
        int startIndex = 0;
        while (startIndex < sb.Length && sb[startIndex] == '0') 
        {
            startIndex++;
        }

        string result = sb.ToString(startIndex, sb.Length - startIndex);
        
        return result.Length == 0 ? "0" : result;
    }
}
```


### Complexity

- **Time Complexity:** $\mathcal{O}(n)$ — Each character is pushed and popped at most once in the loop, and the final reversal and trimming operations take linear time relative to the length of the string.
    
- **Space Complexity:** $\mathcal{O}(n)$ — The stack and the resulting string require linear memory.
