```cs
public class Solution
{
    public int LargestRectangleArea(int[] heights)
    {
        Stack<int> stack = new Stack<int>();
        int maxArea = 0;

        for (int i = 0; i <= heights.Length; i++)
        {
            // Use 0 as a sentinel height at the end to flush out remaining elements
            int currentHeight = (i == heights.Length) ? 0 : heights[i];

            while (stack.Count > 0 && heights[stack.Peek()] > currentHeight)
            {
                int heightIndex = stack.Pop();
                int height = heights[heightIndex];

                int width = (stack.Count == 0) ? i : i - stack.Peek() - 1;

                int area = height * width;
                maxArea = Math.Max(maxArea, area);
            }

            stack.Push(i);
        }

        return maxArea;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $O(n)$
    
    - Every element is pushed onto the stack exactly once and popped from the stack at most once. Thus, the inner `while` loop runs in amortized constant time per element, leading to a linear time complexity where $n$ is the length of the `heights` array.
        
- **Space Complexity:** $O(n)$
    
    - In the worst-case scenario (e.g., when the heights are strictly increasing), all indices will be pushed onto the stack, requiring linear space proportional to the size of the input array.
