
Question: https://leetcode.com/problems/find-median-from-data-stream/description/

Explanation: https://www.youtube.com/watch?v=itmhHWaHupI

```cs
public class MedianFinder
{
    // Smaller half — Max Heap
    private PriorityQueue<int, int> left;

    // Larger half — Min Heap
    private PriorityQueue<int, int> right;

    public MedianFinder()
    {
        left = new PriorityQueue<int, int>(
            Comparer<int>.Create((a, b) => b.CompareTo(a))
        );

        right = new PriorityQueue<int, int>();
    }

    public void AddNum(int num)
    {
        // Step 1: Add to left initially
        if (left.Count == 0 || num <= left.Peek())
        {
            left.Enqueue(num, num);
        }
        else
        {
            right.Enqueue(num, num);
        }

        // Step 2: Balance the heaps
        if (left.Count > right.Count + 1)
        {
            int value = left.Dequeue();
            right.Enqueue(value, value);
        }
        else if (right.Count > left.Count)
        {
            int value = right.Dequeue();
            left.Enqueue(value, value);
        }
    }

    public double FindMedian()
    {
        if (left.Count > right.Count)
        {
            return left.Peek();
        }

        return (left.Peek() + right.Peek()) / 2.0;
    }
}
```

### Complexity Analysis

Let $N$ be the total number of elements added using `AddNum`.

|**Operation**|**Time Complexity**|**Space Complexity**|
|---|---|---|
|**`AddNum`**|$O(\log N)$|$O(1)$ auxiliary memory|
|**`FindMedian`**|$O(1)$|$O(1)$ memory|
|**Overall Structure**|—|$O(N)$ total space|

- **`AddNum` Time:** $O(\log N)$ — Enqueuing and dequeuing operations on binary heaps of size roughly $N/2$ take logarithmic time.
    
- **`FindMedian` Time:** $O(1)$ — Reading the max/min elements via `.Peek()` takes constant time.
    
- **Space Complexity:** $O(N)$ — Required to store all $N$ numbers across the `left` and `right` priority queues.
