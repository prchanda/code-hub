Question: https://leetcode.com/problems/top-k-frequent-elements/description/

```cs
public class Solution {
    public int[] TopKFrequent(int[] nums, int k) {
        Dictionary<int, int> frequency = new Dictionary<int, int>();
        foreach(int num in nums)
        {
            frequency[num] = frequency.GetValueOrDefault(num) + 1;
        }

        PriorityQueue<int, int> pq = new PriorityQueue<int, int>();
        foreach(var kvp in frequency)
        {
            pq.Enqueue(kvp.Key, kvp.Value);
            if(pq.Count > k)
            {
                pq.Dequeue();
            }
        }

        return pq.UnorderedItems.Select(x => x.Element).ToArray();
    }
}
```

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \log K)$, where $N$ is the number of elements in the array. Building the frequency dictionary takes $\mathcal{O}(N)$ time. Inserting into and extracting from the priority queue of size $K$ takes $\mathcal{O}(\log K)$ time for each of the $U$ unique elements (where $U \le N$).
    
- **Space Complexity:** $\mathcal{O}(N)$ auxiliary space to store the frequency map and the priority queue containing up to $K$ (or $U$) elements.
