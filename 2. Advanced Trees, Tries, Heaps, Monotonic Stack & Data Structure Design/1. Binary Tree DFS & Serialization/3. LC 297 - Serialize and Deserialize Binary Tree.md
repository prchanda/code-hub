Question: https://leetcode.com/problems/serialize-and-deserialize-binary-tree/description/

Explanation: https://www.youtube.com/watch?v=u4JAi2JJhI8

```cs
public class Codec 
{
    // Encodes a tree to a single string.
    public string serialize(TreeNode root)
    {
        StringBuilder builder = new StringBuilder();
        SerializeHelper(root, builder);
        
        // Remove the single trailing comma if string isn't empty
        if (builder.Length > 0) 
            builder.Length--; 
        
        return builder.ToString();
    }

    private void SerializeHelper(TreeNode node, StringBuilder builder)
    {
        if (node == null)
        {
            builder.Append("null,");
            return;
        }

        builder.Append(node.val).Append(',');
        SerializeHelper(node.left, builder);
        SerializeHelper(node.right, builder);
    }

    // Decodes your encoded data to tree.
    public TreeNode deserialize(string data)
    {
        if (string.IsNullOrEmpty(data))
            return null;

        string[] tokens = data.Split(',');
        int index = 0;

        return DeserializeHelper(tokens, ref index);
    }

    private TreeNode DeserializeHelper(string[] tokens, ref int index)
    {
        if (index >= tokens.Length || tokens[index] == "null")
        {
            index++;
            return null;
        }

        TreeNode node = new TreeNode(int.Parse(tokens[index]));
        index++;

        node.left = DeserializeHelper(tokens, ref index);
        node.right = DeserializeHelper(tokens, ref index);

        return node;
    }
}

```

#### Serialization (`serialize`)

- **Time Complexity:** $O(N)$ — The pre-order traversal visits every node (and every `null` pointer, which is $N + 1$) exactly once. Appending strings to `StringBuilder` takes $O(1)$ amortized time per operation.
    
- **Space Complexity:** $O(N)$
    
    - **Call Stack:** $O(H)$ where $H$ is the height of the tree ($O(\log N)$ for balanced trees, $O(N)$ for skewed trees).
        
    - **Output Space:** $O(N)$ space required for the `StringBuilder` to hold string tokens for $N$ nodes and $N + 1$ null markers.
        

#### Deserialization (`deserialize`)

- **Time Complexity:** $O(N)$ — Splitting the string into tokens takes $O(N)$ time. Reconstructing each node processes each token exactly once via $O(1)$ operations (`int.Parse` and pointer assignments).
    
- **Space Complexity:** $O(N)$
    
    - **Call Stack:** $O(H)$ recursion depth ($O(\log N)$ average, $O(N)$ worst-case).
        
    - **Auxiliary Memory:** $O(N)$ space to store the `tokens` array generated by `string.Split(',')`.
