## Recursive solution

For **Path Sum III**, use two recursive functions: the outer `PathSum` treats **every node as a possible starting point** by counting valid paths starting from the current node and then recursively calling itself on the left and right subtrees; the inner `CountSumFromCurrentNode` explores all **downward paths from that chosen starting node**, subtracting each node's value from the remaining target and incrementing the count whenever the remaining target becomes `0`, while still continuing down both children because negative values can make the sum reach the target again later. This brute-force approach is **O(N²) in the worst case** because paths are repeatedly explored from different starting nodes, with **O(H)** recursion-stack space; use `long` for the running/remaining sum to avoid integer overflow.

```cs
using System.Collections.Generic;

public class Solution {
    public int PathSum(TreeNode root, int targetSum) {
        // Dictionary tracks how many times a specific prefix sum has occurred.
        // Using 'long' for the sum prevents integer overflow.
        Dictionary<long, int> prefixSums = new Dictionary<long, int>();
        
        // Base case: a prefix sum of 0 has occurred exactly once (an empty path)
        prefixSums[0] = 1;
        
        return DFS(root, 0, targetSum, prefixSums);
    }

    private int DFS(TreeNode node, long currentSum, int targetSum, Dictionary<long, int> prefixSums) {
        if (node == null) return 0;

        currentSum += node.val;
        int count = 0;

        // 1. If (currentSum - targetSum) exists in the dictionary, it means 
        // there is a sub-path ending at this node that equals targetSum.
        if (prefixSums.TryGetValue(currentSum - targetSum, out int matches)) {
            count += matches;
        }

        // 2. Add the current sum to the dictionary so children can use it
        if (!prefixSums.ContainsKey(currentSum)) {
            prefixSums[currentSum] = 0;
        }
        prefixSums[currentSum]++;

        // 3. Traverse children
        count += DFS(node.left, currentSum, targetSum, prefixSums);
        count += DFS(node.right, currentSum, targetSum, prefixSums);

        // 4. Backtrack: Remove the current sum from the dictionary before returning 
        // to the parent node, so parallel branches don't use each other's prefix sums.
        prefixSums[currentSum]--;
        
        return count;
    }
}
```

### Complexity Analysis

- **Time Complexity:**
    
    - **Average Case (Balanced Tree):** $O(N \log N)$. For each node, `CountSumFromCurrentNode` explores its subtrees up to depth $O(\log N)$. Summing across all $N$ nodes yields $O(N \log N)$.
        
    - **Worst Case (Skewed Tree):** $O(N^2)$. If the tree degenerates into a single linked list, the first node traverses $N$ nodes, the second traverses $N - 1$, and so on, resulting in $\sum_{i=1}^{N} i = \frac{N(N+1)}{2}$ operations.
        
- **Space Complexity:**
    
    - **Average Case (Balanced Tree):** $O(\log N)$ auxiliary space for the recursion call stack.
        
    - **Worst Case (Skewed Tree):** $O(N)$ auxiliary space for the recursion call stack equal to tree height $H$.
