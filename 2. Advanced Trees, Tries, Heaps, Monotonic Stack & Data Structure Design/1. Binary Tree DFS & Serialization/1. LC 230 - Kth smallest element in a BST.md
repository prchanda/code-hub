Question: https://leetcode.com/problems/kth-smallest-element-in-a-bst/solutions/

Explanation: https://www.youtube.com/watch?v=5LUXSvjmGCw


```cs
public class Solution
{
    public int KthSmallest(TreeNode root, int k)
    {
        int count = 0;
        return DFS(root, k, ref count) ?? -1;
    }
	
	// Took nullable int because if there are negative numbers in the array
    private int? DFS(TreeNode root, int k, ref int count)
    {
        if (root == null)
            return null;

        // Traverse left subtree
        int leftResult? = DFS(root.left, k, ref count);
        if (leftResult.HasValue)
            return leftResult;

        // Visit current node
        count++;
        if (count == k)
            return root.val;

        // Traverse right subtree
        return DFS(root.right, k, ref count);
    }
}
```


### Complexity Analysis

- **Time Complexity:** $O(H + K)$, where $H$ is the height of the tree.
    
    - **Average Case (Balanced Tree):** $O(\log N + K)$. The algorithm traverses down to the leftmost leaf ($O(\log N)$) and then visits $K$ nodes before returning early.
        
    - **Worst Case (Skewed Tree):** $O(N)$, occurring when the tree degenerates into a linked list or when $K = N$.
        
- **Space Complexity:** $O(H)$ auxiliary space for the call stack.
    
    - **Average Case (Balanced Tree):** $O(\log N)$ stack depth.
        
    - **Worst Case (Skewed Tree):** $O(N)$ stack depth.
