### **Problem Statement**

You are given an integer array `nums` of length `n` where `nums` is a permutation of the integers in the range `[1, n]`. You are also given a 2D integer array `sequences` where `sequences[i]` is a subsequence of `nums`.

Check whether `nums` is the **only** possible shortest common supersequence. That means:

1. `nums` must be a supersequence of all arrays in `sequences` (every sequence in `sequences` is a subsequence of `nums`).
    
2. There are **no other** valid shortest common supersequences. In other words, the given `sequences` must uniquely determine the order of elements, resulting in a single unique topological ordering that matches `nums`.
    

Return `true` if `nums` is the only shortest common supersequence for `sequences`, or `false` otherwise.

### **Examples**

#### **Example 1:**

- **Input:** `nums = [1,2,3]`, `sequences = [[1,2],[1,3]]`
    
- **Output:** `false`
    
- **Explanation:** There are two possible valid supersequences: `[1,2,3]` and `[1,3,2]`. Both contain `[1,2]` and `[1,3]` as subsequences. Because the sequence is not unique, the answer is `false`.
    

#### **Example 2:**

- **Input:** `nums = [1,2,3]`, `sequences = [[1,2]]`
    
- **Output:** `false`
    
- **Explanation:** The shortest possible supersequence can only be `[1,2]`, which does not match `nums`.
    

#### **Example 3:**

- **Input:** `nums = [1,2,3]`, `sequences = [[1,2],[1,3],[2,3]]`
    
- **Output:** `true`
    
- **Explanation:** The unique sequence that can be reconstructed from `[1,2]`, `[1,3]`, and `[2,3]` is `[1,2,3]`, which matches `nums`.
    

### **Constraints:**

- `n == nums.length`
    
- $1 \le n \le 10^4$
    
- `nums` is a permutation of all the integers in the range `[1, n]`.
    
- $1 \le \text{sequences.length} \le 10^4$
    
- $1 \le \text{sequences[i].length} \le 10^4$
    
- $1 \le \sum \text{sequences[i].length} \le 10^5$
    
- $1 \le \text{sequences[i][j]} \le n$
    
- All the arrays of `sequences` are unique.
    
- `sequences[i]` is a subsequence of `nums`.


```cs
public class Solution
{
    public bool SequenceReconstruction(int[] nums, IList<IList<int>> sequences)
    {
        int n = nums.Length;

        List<int>[] graph = new List<int>[n + 1];
        int[] indegree = new int[n + 1];

        for (int i = 1; i <= n; i++)
        {
            graph[i] = new List<int>();
        }

        foreach (var sequence in sequences)
        {
            for (int i = 1; i < sequence.Count; i++)
            {
                int from = sequence[i - 1];
                int to = sequence[i];

                // Avoid duplicate edges
                if (!graph[from].Contains(to))
                {
                    graph[from].Add(to);
                    indegree[to]++;
                }
            }
        }

        Queue<int> queue = new Queue<int>();

        for (int i = 1; i <= n; i++)
        {
            if (indegree[i] == 0)
                queue.Enqueue(i);
        }

        int index = 0;

		// Multiple choices => multiple valid topological orders, so size has to be 1 for unique combination
		// Topological sort + exactly one node available at every step = unique topological ordering.
		//     1
		//    / \
		//   2   3
		// Both are possible: [1,2,3] and [1,3,2], when doing TopSort
		// But if I take this example: Input: nums = [1,2,3], sequences = [[1,2],[1,3],[2,3]]
		//     1
		//    / \
		//   2 - 3
		// Then at each, there is only one node have indegree = 0 which means I can queue only 1 node, which mean there is only unique path to traverse
        while (queue.Count == 1)
        {
            int current = queue.Dequeue();

            // Must reconstruct nums exactly
            if (current != nums[index])
                return false;

            index++;

            foreach (int neighbor in graph[current])
            {
                indegree[neighbor]--;

                if (indegree[neighbor] == 0)
                    queue.Enqueue(neighbor);
            }
        }

        return index == n;
    }
}
```
