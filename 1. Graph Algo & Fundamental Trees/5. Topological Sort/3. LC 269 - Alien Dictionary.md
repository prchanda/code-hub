There is a new alien language that uses the Latin alphabet. However, the order among the letters is unknown to you. 
You are given a list of strings `words` from the alien language's dictionary, where the strings in `words` are **sorted lexicographically** according to the rules of this new language.
Return a string of the unique letters in the new alien language sorted in **lexicographically increasing order** by the new language's rules. If there is no possible order of letters, return `""`. If there are multiple valid orders, return **any of them**.

### Key Definition

A string `s` is **lexicographically smaller** than a string `t` if at the first index where `s` and `t` differ, the character in `s` comes before the character in `t` in the alien alphabet. If `s` is a prefix of `t` (e.g., `"ab"` vs `"abc"`), then `s` is smaller than `t`.

### Examples

#### Example 1

- **Input:** `words = ["wrt","wrf","er","ett","rftt"]`
    
- **Output:** `"wertf"`
    
- **Explanation:**
    
    1. From `"wrt"` and `"wrf"` $\rightarrow$ `'t'` comes before `'f'`
        
    2. From `"wrf"` and `"er"` $\rightarrow$ `'w'` comes before `'e'`
        
    3. From `"er"` and `"ett"` $\rightarrow$ `'r'` comes before `'t'`
        
    4. From `"ett"` and `"rftt"` $\rightarrow$ `'e'` comes before `'r'`
        
    
    Combining these rules yields the order: `"wertf"`.
    

#### Example 2

- **Input:** `words = ["z","x"]`
    
- **Output:** `"zx"`
    

#### Example 3

- **Input:** `words = ["z","x","z"]`
    
- **Output:** `""`
    
- **Explanation:** The order is invalid because `'z'` comes before `'x'`, but `'x'` also comes before `'z'`. (Forms a cycle).
    

#### Example 4 (Important Edge Case)

- **Input:** `words = ["abc","ab"]`
    
- **Output:** `""`
    
- **Explanation:** `"abc"` comes before `"ab"`, which violates standard prefix ordering (a longer string with the same prefix cannot come before a shorter one). Thus, the order is invalid.
    

### Constraints

- $1 \le \text{words.length} \le 100$
    
- $1 \le \text{words}[i].\text{length} \le 100$
    
- `words[i]` consists of only lowercase English letters.

```cs
public class Solution
{
    public string AlienOrder(string[] words)
    {
        // Step 1: Initialize every character.
        // All characters must be initialized because some may have zero edges. Characters = nodes. 
        // Then Kahn's BFS finds an ordering satisfying all those edges.
        // Imagine: words = ["abc", "abd"]. We discover only: c → d. But `a` and `b` are also valid characters and must be included in TopSort.
        Dictionary<char, HashSet<char>> graph = new Dictionary<char, HashSet<char>>();
        Dictionary<char, int> indegree = new Dictionary<char, int>();

        foreach (string word in words)
        {
            foreach (char c in word)
            {
                if (!graph.ContainsKey(c))
                {
                    graph[c] = new HashSet<char>();
                    indegree[c] = 0;
                }
            }
        }

        // Step 2: Build the directed graph.
        // Compare adjacent words.
        for (int i = 0; i < words.Length - 1; i++)
        {
            string first = words[i];
            string second = words[i + 1];

            int minLength = Math.Min(first.Length, second.Length);

            bool foundDifference = false;

            for (int j = 0; j < minLength; j++)
            {
                if (first[j] != second[j])
                {
                    char from = first[j];
                    char to = second[j];

                    // Avoid duplicate edges. First differing character between adjacent words = directed edge.
                    if (graph[from].Add(to))
                    {                        
                        indegree[to]++;
                    }

                    foundDifference = true;
                    break;
                }
            }

            // Invalid case:
            // ["abc", "ab"]            
            // Longer word comes before its prefix.
            if (!foundDifference && first.Length > second.Length)
            {
                return "";
            }
        }

        // Step 3: Add all characters with indegree 0.
        Queue<char> queue = new Queue<char>();

        foreach (char c in indegree.Keys)
        {
            if (indegree[c] == 0)
            {
                queue.Enqueue(c);
            }
        }

        // Step 4: Kahn's Algorithm.
        StringBuilder result = new StringBuilder();

        while (queue.Count > 0)
        {
            char current = queue.Dequeue();

            result.Append(current);

            foreach (char neighbour in graph[current])
            {
                indegree[neighbour]--;

                if (indegree[neighbour] == 0)
                {
                    queue.Enqueue(neighbour);
                }
            }
        }

        // If we couldn't process every character,
        // there is a cycle.
        if (result.Length != indegree.Count)
        {
            return "";
        }

        return result.ToString();
    }
}
```

| **Metric**           |   **Complexity** | **Details**                                                                                                                                                                                                                                                                            |
| -------------------- | ---------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | **O(C + V + E)** | **Graph construction:** We scan the characters of adjacent words, which is O(C) overall. `Contains()` for duplicate edges can add work depending on the graph representation. **Topological Sort:** Every character is processed once → O(V), and every edge is processed once → O(E). |
| **Space Complexity** |     **O(V + E)** | **Graph:** O(V + E). **Indegree:** O(V). **Queue:** O(V). **Result:** O(V).                                                                                                                                                                                                            |
