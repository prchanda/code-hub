### Problem Statement

You are given an empty $m \times n$ 2D binary grid filled with water (represented by `0`s). 
You perform a series of **add land** operations that convert water cells to land cells (represented by `1`s). You are given an array `positions` where $\text{positions}[i] = [r_i, c_i]$ represents the cell coordinates for the $i^{\text{th}}$ operation.
Return an array `answer` where `answer[i]` is the **number of islands** present in the grid after turning cell $(r_i, c_i)$ into land.
An **island** is surrounded by water and is formed by connecting adjacent lands horizontally or vertically (4-directional). You may assume all four edges of the grid are completely surrounded by water.

### Examples

#### Example 1

- **Input:** `m = 3`, `n = 3`, `positions = [[0,0],[0,1],[1,2],[2,1]]`    
- **Output:** `[1, 1, 2, 3]`
    
- **Explanation:**
    1. `addLand(0, 0)`: Adds land at `(0,0)`. $\rightarrow$ **1 island**        
    2. `addLand(0, 1)`: Adds land at `(0,1)`. It connects with `(0,0)`. $\rightarrow$ **1 island**        
    3. `addLand(1, 2)`: Adds land at `(1,2)`. It is isolated from existing land. $\rightarrow$ **2 islands**        
    4. `addLand(2, 1)`: Adds land at `(2,1)`. It is isolated from existing land. $\rightarrow$ **3 islands**
        

#### Example 2
- **Input:** `m = 1`, `n = 1`, `positions = [[0,0]]`    
- **Output:** `[1]`
    
### Constraints

- $1 \le m, n \le 10^4$
- $1 \le m \times n \le 10^4$    
- $1 \le \text{positions.length} \le 10^4$    
- $\text{positions}[i].\text{length} == 2$    
- $0 \le r_i < m$    
- $0 \le c_i < n$.

```cs
public class Solution
{
    public IList<int> NumIslands2(int m, int n, int[][] positions)
    {
        List<int> result = new List<int>();

        int[] parent = new int[m * n];
        int[] rank = new int[m * n];

        Array.Fill(parent, -1);

        int count = 0;

        int[][] directions =
        {
            new[] { -1, 0 },
            new[] { 1, 0 },
            new[] { 0, -1 },
            new[] { 0, 1 }
        };

        foreach (int[] pos in positions)
        {
            int r = pos[0];
            int c = pos[1];
            int id = r * n + c;

            // Duplicate position
            if (parent[id] != -1)
            {
                result.Add(count);
                continue;
            }

            // Create new island
            parent[id] = id;
            count++;

            foreach (int[] dir in directions)
            {
                int nr = r + dir[0];
                int nc = c + dir[1];

                if (nr < 0 || nr >= m || nc < 0 || nc >= n)
                    continue;

                int neighborId = nr * n + nc;

                // Neighbor is water
                if (parent[neighborId] == -1)
                    continue;

                // If two islands were merged, island count decreases
                if (Union(parent, rank, id, neighborId))
                {
                    count--;
                }
            }

            result.Add(count);
        }

        return result;
    }

    private bool Union(int[] parent, int[] rank, int x, int y)
    {
        int rootX = Find(parent, x);
        int rootY = Find(parent, y);

        // Already connected
        if (rootX == rootY)
            return false;

        if (rank[rootX] < rank[rootY])
        {
            parent[rootX] = rootY;
        }
        else if (rank[rootX] > rank[rootY])
        {
            parent[rootY] = rootX;
        }
        else
        {
            parent[rootY] = rootX;
            rank[rootX]++;
        }

        return true;
    }

    private int Find(int[] parent, int x)
    {
        if (parent[x] != x)
        {
            parent[x] = Find(parent, parent[x]);
        }

        return parent[x];
    }
}
```

## Complexity Analysis

Let $k$ be the number of land addition operations (`positions.Length`), and $N = m \times n$ be the total cells.

- **Time Complexity:** $O(k \cdot \alpha(m \times n))$    
    - Each `Find` and `Union` operation with path compression takes $O(\alpha(N))$ amortized time, where $\alpha$ is the Inverse Ackermann function ($\le 4$ for all practical input sizes).        
    - Thus, processing $k$ positions takes virtually $O(k)$ time.
        
- **Space Complexity:** $O(m \times n)$    
    - The `parent` array requires space proportional to the grid size $m \times n$.
