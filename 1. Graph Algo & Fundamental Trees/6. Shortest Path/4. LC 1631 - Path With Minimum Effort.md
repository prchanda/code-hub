Question: https://leetcode.com/problems/path-with-minimum-effort/

```cs
public class Solution
{
    public int MinimumEffortPath(int[][] heights)
    {
        int rows = heights.Length;
        int cols = heights[0].Length;

        int[,] effort = new int[rows, cols];

        // Initially every cell is unreachable.
        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < cols; col++)
            {
                effort[row, col] = int.MaxValue;
            }
        }

        effort[0, 0] = 0;

        int[,] directions =
        {
            { -1, 0 },
            { 1, 0 },
            { 0, -1 },
            { 0, 1 }
        };

        PriorityQueue<(int row, int col), int> queue =
            new PriorityQueue<(int row, int col), int>();

        queue.Enqueue((0, 0), 0);

        while (queue.Count > 0)
        {
            var (row, col) = queue.Dequeue();
            int currentEffort = effort[row, col];

            // Destination reached with minimum possible effort.
            if (row == rows - 1 && col == cols - 1)
            {
                return currentEffort;
            }

            for (int dir = 0; dir < 4; dir++)
            {
                int newRow = row + directions[dir, 0];
                int newCol = col + directions[dir, 1];

                if (newRow < 0 || newRow >= rows ||
                    newCol < 0 || newCol >= cols)
                {
                    continue;
                }

                int edgeEffort = Math.Abs(heights[row][col] - heights[newRow][newCol]);                
                int newEffort = Math.Max(currentEffort, edgeEffort);

                if (newEffort < effort[newRow, newCol])
                {
                    effort[newRow, newCol] = newEffort;
                    queue.Enqueue((newRow, newCol), newEffort);
                }
            }
        }

        return 0;
    }
}
```

## Complexity Analysis

Let $R = \text{rows}$ and $C = \text{cols}$. Total number of vertices in the grid is $V = R \times C$. Since each cell has at most $4$ neighbours, the total number of edges is $E \le 4 \times R \times C = \mathcal{O}(R \cdot C)$.

### **Time Complexity:** $\mathcal{O}(R \cdot C \log(R \cdot C))$

- **Priority Queue Operations:** In the worst-case scenario, every edge relaxation adds an element to the priority queue. With up to $E = \mathcal{O}(R \cdot C)$ elements in the priority queue, each `Enqueue` and `Dequeue` operation takes $\mathcal{O}(\log(R \cdot C))$ time.
    
- **Total Work:** Relaxing all $E$ edges takes $\mathcal{O}(E \log V) = \mathcal{O}(R \cdot C \log(R \cdot C))$ time.
    

### **Space Complexity:** $\mathcal{O}(R \cdot C)$

- **Effort Grid:** The 2D array storing minimum effort per cell requires $\mathcal{O}(R \cdot C)$ space.
    
- **Priority Queue:** The heap can hold at most $E = \mathcal{O}(R \cdot C)$ entries at any given point in time.
    
- **Overall Space:** $\mathcal{O}(R \cdot C)$.
