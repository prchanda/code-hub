Question: https://leetcode.com/problems/cheapest-flights-within-k-stops/description/

```cs
public class Solution 
{
    public int FindCheapestPrice(int n, int[][] flights, int src, int dst, int k) 
    {
        int[] prices = new int[n];

        // Initially mark all cities as unreachable
        Array.Fill(prices, int.MaxValue);

        // Cost to reach the source city is 0
        prices[src] = 0;

        /* At most k stops = at most k + 1 flights
        Iteration 0
		    ↓
		Allow 1 flight
		
		Iteration 1
		    ↓
		Allow 2 flights
		
		Iteration 2
		    ↓
		Allow 3 flights
        
        */
        
        for (int i = 0; i <= k; i++)
        {
            // Clone prices to prevent taking multiple flights within a single layer            
			// Why don't we simply update `prices` directly?
			// Because we want each iteration to represent exactly one additional flight.
            int[] next = (int[])prices.Clone();
			
            foreach (int[] flight in flights)
            {
                int from = flight[0];
                int to = flight[1];
                int cost = flight[2];

                // Skip if source city was unreachable in the previous layer
                if (prices[from] != int.MaxValue && prices[from] + cost < next[to])
                {
	                next[to] = prices[from] + cost;
                }
            }

            prices = next;
        }

        return prices[dst] == int.MaxValue ? -1 : prices[dst];
    }
}
```

## Complexity Analysis

Let $V = n$ be the number of cities (vertices), $E = \text{flights.Length}$ be the number of flights (edges), and $K = k$ be the maximum allowed stops.

### **Time Complexity:** $\mathcal{O}(K \cdot (E + V))$

- **Initialization:** Setting up the `prices` array takes $\mathcal{O}(V)$ time.
    
- **Outer Loop:** Runs $K + 1$ times.
    
    - Cloning the `prices` array in each step takes $\mathcal{O}(V)$ time.
        
    - The inner loop iterates over all $E$ flights, performing $\mathcal{O}(1)$ operations per flight.
        
- **Total Time:** $\mathcal{O}((K + 1) \cdot (E + V))$, which simplifies to **$\mathcal{O}(K \cdot E)$** (since $E \ge V$ in most connected graph scenarios).
    

### **Space Complexity:** $\mathcal{O}(V)$

- **Price Arrays:** We maintain two 1D arrays (`prices` and `next`) of size $n$ to store minimum costs per city.
    
- **Overall Space:** **$\mathcal{O}(V)$** auxiliary memory.


## Bellman-Ford algorithm


The Bellman-Ford algorithm is a method used to find the shortest paths from a single starting node to all other nodes in a weighted directed graph.

How It Works

- **Initialization:** Set the distance to the starting node to zero and all other nodes to infinity.

- **Relaxation:** Repeat a process called "relaxation" for all edges V - 1 times, where V is the number of vertices.

- **Updating values:** For an edge from node u to node v with weight w, if the distance to u plus w is less than the current distance to v, update v's distance.

- **Negative cycles:** Run a final check on all edges; if any distance can still be shortened, the graph contains a negative weight cycle.


```cs
public class BellmanFord
{
    public static void FindShortestPaths(List<Edge> edges, int vertices, int source)
    {
        int[] distance = Enumerable.Repeat(int.MaxValue, vertices).ToArray();
        distance[source] = 0;

        for (int i = 1; i < vertices; i++)
        {
            foreach (var edge in edges)
            {
                if (distance[edge.Source] != int.MaxValue &&
                    distance[edge.Source] + edge.Weight < distance[edge.Destination])
                {
                    distance[edge.Destination] = distance[edge.Source] + edge.Weight;
                }
            }
        }

        // Negative weight cycle check
        foreach (var edge in edges)
        {
            if (distance[edge.Source] != int.MaxValue &&
                distance[edge.Source] + edge.Weight < distance[edge.Destination])
            {
                Console.WriteLine("Graph contains a negative weight cycle");
                return;
            }
        }

        for (int i = 0; i < vertices; i++)
        {
            Console.WriteLine($"Distance from source {source} to {i}: {distance[i]}");
        }
    }
}
```
