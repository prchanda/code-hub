Explanation: https://www.youtube.com/watch?v=h9iTnkgv05E

```cs
public class Solution {
    public int LadderLength(string beginWord, string endWord, IList<string> wordList) {
        HashSet<string> dictionary = new HashSet<string>(wordList);

        if(!dictionary.Contains(endWord))
            return 0;

        Queue<string> queue = new Queue<string>();
        queue.Enqueue(beginWord);
        int distance = 1;

        while(queue.Count > 0)
        {
            int size = queue.Count;            
            for(int layer = 0; layer < size; layer++)
            {
                string word = queue.Dequeue();
                var wordArray = word.ToCharArray();
                
                for(int index = 0; index < wordArray.Length; index++)
                {
                    char originalChar = wordArray[index];
                    for(char chr = 'a'; chr <= 'z'; chr++)
                    {
                        if(chr == originalChar)
                            continue;
                            
                        wordArray[index] = chr;
                        string newWord = new string(wordArray);
                        
                        if(newWord == endWord)
                            return distance + 1;                        
                            
                        if(dictionary.Contains(newWord))
                        {
                            queue.Enqueue(newWord);
                            dictionary.Remove(newWord);
                        }       
                    }
                    wordArray[index] = originalChar;
                }
            }
            distance++;            
        }
        return 0;
    }
}

```

# Complexity

Let:

- **N** = number of words in `wordList`
- **L** = length of each word
- Alphabet size = **26**

| **Metric**           | **Complexity**                        | **Details**                                                                                                                                                                                     |
| -------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | **O(N × L × 26 × L)** = **O(N × L²)** | Each word is processed at most once. For each word, we try `26` characters at each of its `L` positions. Creating `new string(chars)` takes O(L). Since 26 is constant, this becomes O(N × L²). |
| **Space Complexity** | **O(N × L)**                          | `HashSet` stores up to N words, each of length L. The BFS queue can contain O(N) words, and the generated strings temporarily require O(L) space.                                               |


Optimized version using Bi-Directional BFS using 2 HashSet one starting from beginning and other starting from end. This helps in dramatically reducing the number of words explored. Suppose the branching factor is roughly `b` and shortest path length is `d`. Normal BFS explores approximately: `b^d` 
Bidirectional BFS explores approximately: `2 × b^(d/2)`

While Bidirectional BFS shares the same theoretical worst-case bound $O(N \cdot L^2)$ as standard BFS, it drastically reduces the **search tree volume**:

- **Unidirectional BFS Search Volume:** $O(b^d)$, where $b$ is the branching factor and $d$ is the shortest path depth.
    
- **Bidirectional BFS Search Volume:** $O(2 \cdot b^{d/2})$, which expands exponentially fewer nodes by meeting in the middle.

```cs
public class Solution
{
    public int LadderLength(
        string beginWord,
        string endWord,
        IList<string> wordList)
    {
        HashSet<string> dictionary = new HashSet<string>(wordList);

        if (!dictionary.Contains(endWord))
            return 0;

        HashSet<string> beginSet = new HashSet<string> { beginWord };
        HashSet<string> endSet = new HashSet<string> { endWord };

        dictionary.Remove(beginWord);
        dictionary.Remove(endWord);

        int distance = 1;

        while (beginSet.Count > 0 && endSet.Count > 0)
        {
            // Always expand the smaller frontier
            if (beginSet.Count > endSet.Count)
            {
                HashSet<string> temp = beginSet;
                beginSet = endSet;
                endSet = temp;
            }

            HashSet<string> nextLevel = new HashSet<string>();

            foreach (string word in beginSet)
            {
                char[] chars = word.ToCharArray();

                for (int i = 0; i < chars.Length; i++)
                {
                    char original = chars[i];

                    for (char c = 'a'; c <= 'z'; c++)
                    {
                        if (c == original)
                            continue;

                        chars[i] = c;
                        string newWord = new string(chars);

                        // The two BFS searches have met
                        if (endSet.Contains(newWord))
                            return distance + 1;

                        if (dictionary.Contains(newWord))
                        {
                            dictionary.Remove(newWord);
                            nextLevel.Add(newWord);
                        }
                    }

                    chars[i] = original;
                }
            }

            beginSet = nextLevel;
            distance++;
        }

        return 0;
    }
}
```
