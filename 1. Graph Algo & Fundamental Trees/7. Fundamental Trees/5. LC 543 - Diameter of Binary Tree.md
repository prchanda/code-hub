Question: https://leetcode.com/problems/diameter-of-binary-tree/

```cs
public class Solution
{
    private int diameter = 0;

    public int DiameterOfBinaryTree(TreeNode root)
    {
        Height(root);
        return diameter;
    }

    private int Height(TreeNode node)
    {
        if (node == null)
            return 0;

        int leftHeight = Height(node.left);
        int rightHeight = Height(node.right);

        // Longest path (number of edges) passing through this node
        int pathThroughNode = leftHeight + rightHeight;

        // Update the maximum diameter found so far
        diameter = Math.Max(diameter, pathThroughNode);

        // Return height of current subtree to the parent node
        return 1 + Math.Max(leftHeight, rightHeight);
    }
}
```

## Complexity Analysis

Let $N$ be the total number of nodes in the binary tree and $H$ be the height of the tree.

- **Time Complexity:** $\mathcal{O}(N)$ — Every node is visited once in a post-order traversal (bottom-up DFS), performing $\mathcal{O}(1)$ work per node.
    
- **Space Complexity:** $\mathcal{O}(H)$ — Memory used by the implicit recursive call stack.
    
    - **Balanced Tree:** $\mathcal{O}(\log N)$
        
    - **Skewed Tree:** $\mathcal{O}(N)$
