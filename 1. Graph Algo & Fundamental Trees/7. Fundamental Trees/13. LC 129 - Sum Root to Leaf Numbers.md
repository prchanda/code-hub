Question: https://leetcode.com/problems/sum-root-to-leaf-numbers/description/

```cs
public class Solution {
    private int totalSum = 0;
    
    public int SumNumbers(TreeNode root) {
        SumNumbersHelper(root, 0);
        return totalSum;
    }

    private void SumNumbersHelper(TreeNode root, int currentSum)
    {
        if (root == null)
            return;

        currentSum = currentSum * 10 + root.val;

        if (root.left == null && root.right == null)
        {
            totalSum += currentSum;
        }

        SumNumbersHelper(root.left, currentSum);
        SumNumbersHelper(root.right, currentSum);
    }
}
```

### Complexity Analysis

- **Time Complexity:** $O(N)$, where $N$ is the number of nodes in the binary tree. Every node is visited exactly once during the depth-first search traversal.
    
- **Space Complexity:** $O(H)$ (or $O(N)$ in the worst-case for a skewed tree), where $H$ is the height of the tree, accounting for the maximum depth of the recursive call stack.
