Question: https://leetcode.com/problems/binary-tree-maximum-path-sum/description/

```cs
public class Solution 
{
    private int _maxSum = int.MinValue;

    public int MaxPathSum(TreeNode root) 
    {
        Gain(root);
        return _maxSum;
    }

    private int Gain(TreeNode node)
    {
        if (node == null)
            return 0;

        // Recursively compute maximum contribution from left and right subtrees.
        // Ignore negative path gains by taking Math.Max(0, ...).
        int leftGain = Math.Max(0, Gain(node.left));
        int rightGain = Math.Max(0, Gain(node.right));

        // Max path sum passing through the current node as the highest root/bridge
        int passThroughSum = node.val + leftGain + rightGain;

        // Update global maximum path sum found so far
        _maxSum = Math.Max(_maxSum, passThroughSum);

        // Return maximum branch gain to continue the path up to the parent
        return node.val + Math.Max(leftGain, rightGain);
    }
}
```

## Complexity Analysis

Let $N$ be the total number of nodes in the binary tree and $H$ be the height of the tree.

- **Time Complexity:** $\mathcal{O}(N)$ — Every node is visited exactly once in a bottom-up (post-order) traversal, doing $\mathcal{O}(1)$ work at each node.
    
- **Space Complexity:** $\mathcal{O}(H)$ — Memory used by the implicit recursive call stack.
    
    - **Balanced Tree:** $\mathcal{O}(\log N)$        
    - **Skewed Tree:** $\mathcal{O}(N)$
