Question: https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/description/

Explanation: https://www.youtube.com/watch?v=ihj4IQGZ2zc

```cs
public class Solution
{
    private Dictionary<int, int> inorderIndex;
    private int preorderIndex;

    public TreeNode BuildTree(int[] preorder, int[] inorder)
    {
        inorderIndex = new Dictionary<int, int>();

        for (int i = 0; i < inorder.Length; i++)
        {
            inorderIndex[inorder[i]] = i;
        }

        preorderIndex = 0;

        return Build(preorder, 0, inorder.Length - 1);
    }

    private TreeNode Build(int[] preorder, int left, int right)
    {
        // No elements in this subtree
        if (left > right)
            return null;

        // Preorder gives us the root
        int rootValue = preorder[preorderIndex++];
        TreeNode root = new TreeNode(rootValue);

        // Find root position in inorder
        int rootIndex = inorderIndex[rootValue];

        // Everything before rootIndex belongs to left subtree
        root.left = Build(preorder, left, rootIndex - 1);

        // Everything after rootIndex belongs to right subtree
        root.right = Build(preorder, rootIndex + 1, right);

        return root;
    }
}
```

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$, where $N$ is the number of nodes in the tree. The dictionary reduces the inorder index lookup time from $\mathcal{O}(N)$ to $\mathcal{O}(1)$ for each of the $N$ nodes, making the overall building process linear.
    
- **Space Complexity:** $\mathcal{O}(N)$ to store the dictionary mapping and to maintain the recursion call stack in the worst-case scenario (a skewed tree).
