Question: https://leetcode.com/problems/same-tree/

```cs
public class Solution
{
    public bool IsSameTree(TreeNode p, TreeNode q)
    {
        // Both nodes are null -> identical structural end
        if (p == null && q == null)
            return true;

        // One node is null while the other is not -> structural mismatch
        if (p == null || q == null)
            return false;

        // Node values do not match
        if (p.val != q.val)
            return false;

        // Recursively check left and right subtrees
        return IsSameTree(p.left, q.left) && IsSameTree(p.right, q.right);
    }
}
```

## Complexity Analysis

Let $N$ be the minimum number of nodes between tree `p` and tree `q`, and $H$ be the height of the trees.

- **Time Complexity:** $\mathcal{O}(N)$ — In the worst case (where both trees are identical), every node up to $N$ is visited once.

- **Space Complexity:** $\mathcal{O}(H)$ — Call stack space required for recursion.
    
    - **Balanced Tree:** $\mathcal{O}(\log N)$
        
    - **Skewed Tree:** $\mathcal{O}(N)$
