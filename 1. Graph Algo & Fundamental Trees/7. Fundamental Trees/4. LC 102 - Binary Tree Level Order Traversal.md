Question: https://leetcode.com/problems/binary-tree-level-order-traversal/

```cs
public class Solution 
{
    public IList<IList<int>> LevelOrder(TreeNode root) 
    {
        IList<IList<int>> result = new List<IList<int>>();

        if (root == null)
            return result;

        Queue<TreeNode> queue = new Queue<TreeNode>();
        queue.Enqueue(root);

        while (queue.Count > 0)
        {
            int size = queue.Count;
            List<int> levelNodes = new List<int>();

            for (int i = 0; i < size; i++)
            {
                TreeNode element = queue.Dequeue();
                levelNodes.Add(element.val);

                if (element.left != null)
                    queue.Enqueue(element.left);

                if (element.right != null)
                    queue.Enqueue(element.right);
            }

            result.Add(levelNodes);
        }

        return result;
    }
}
```

## Complexity Analysis

Let $N$ be the total number of nodes in the binary tree and $W$ be the maximum width (number of nodes at any single level) of the tree.

- **Time Complexity:** $\mathcal{O}(N)$ — Every node is enqueued and dequeued exactly once, performing $\mathcal{O}(1)$ operations per node.
    
- **Space Complexity:** $\mathcal{O}(N)$
    
    - **Queue Storage:** The queue holds at most $W$ nodes at a time. In a balanced/full binary tree, the lowest layer contains $W \approx \frac{N}{2}$ nodes, taking $\mathcal{O}(N)$ auxiliary space.
        
    - **Result Storage:** Storing all node values in the output list `result` takes $\mathcal{O}(N)$ space.
