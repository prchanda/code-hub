Question : https://leetcode.com/problems/clone-graph/

```cs
/*
// Definition for a Node.
public class Node 
{
    public int val;
    public IList<Node> neighbors;

    public Node() 
    {
        val = 0;
        neighbors = new List<Node>();
    }

    public Node(int _val) 
    {
        val = _val;
        neighbors = new List<Node>();
    }

    public Node(int _val, List<Node> _neighbors) 
    {
        val = _val;
        neighbors = _neighbors;
    }
}
*/

public class Solution 
{
    public Node CloneGraph(Node node) 
    {
        if (node == null)
            return null;

        Dictionary<Node, Node> lookup = new();
        return DeepCopy(node, lookup);
    }

    private Node DeepCopy(Node node, Dictionary<Node, Node> lookup)
    {
        // If node was already cloned, return the existing clone to handle cycles
        if (lookup.ContainsKey(node))
            return lookup[node];

        // Create new clone and register in lookup before recurring on neighbors
        var clone = new Node(node.val);
        lookup[node] = clone;

        foreach (var neighbor in node.neighbors)
        {
            clone.neighbors.Add(DeepCopy(neighbor, lookup));
        }

        return clone;
    }
}
```

| **Metric**           | **Complexity** | **Details**                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | $O(N + M)$     | **Node Visits:** Each unique node is visited and created exactly once, taking $O(N)$ time. <br>  <br>**Edge Traversal:** The `foreach` loop iterates over every neighbor list. For an undirected graph, each edge is traversed twice across all nodes, taking $O(M)$ total iterations.                                                                                                                                                   |
| **Space Complexity** | $O(N + M)$     | **Lookup Dictionary:** Stores $N$ key-value pairs mapping original nodes to cloned nodes ($O(N)$ space).<br><br>**Recursion Stack:** In the worst-case scenario (a single connected chain or tree), the DFS call stack reaches a depth of $O(N)$.<br><br>**New Graph Allocation:** The output cloned graph itself contains $N$ nodes and $2M$ total neighbor references ($O(N + M)$ space).<br><br>Therefore, total space is $O(N + M)$. |
