
Question: https://leetcode.com/problems/course-schedule/

```cs
public class Solution
{
    // Node state definitions for readability
    private const int Unvisited = 0;
    private const int Visiting = 1;
    private const int Visited = 2;

    public bool CanFinish(int numCourses, int[][] prerequisites)
    {
        List<int>[] graph = new List<int>[numCourses];

        for (int i = 0; i < numCourses; i++)
        {
            graph[i] = new List<int>();
        }

        // Build directed graph: prerequisite -> course
        foreach (var edge in prerequisites)
        {
            int course = edge[0];
            int pre = edge[1];

            graph[pre].Add(course);
        }

        int[] states = new int[numCourses];

        // Check for cycles starting from each course
        for (int i = 0; i < numCourses; i++)
        {
            if (HasCycle(graph, i, states))
                return false;
        }

        return true;
    }

    private bool HasCycle(List<int>[] graph, int node, int[] states)
    {
        // Cycle detected: currently visiting this node in the active call stack
        if (states[node] == Visiting)
            return true;

        // Fully processed node: no cycle along this path
        if (states[node] == Visited)
            return false;

        states[node] = Visiting;

        foreach (var neighbor in graph[node])
        {
            if (HasCycle(graph, neighbor, states))
                return true;
        }

        states[node] = Visited;
        return false;
    }
}
```


| **Metric**           | **Complexity** | **Details**                                                                                                                                                                                                                                                                                                                                                                                                               |
| -------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | $O(V + E)$     | **Graph Construction:** Scans all $V$ courses and $E$ prerequisite pairs to build the directed adjacency list in $O(V + E)$ time.<br><br>**DFS Traversal:** Each course is marked `Visiting` and `Visited` at most once ($O(V)$). Each directed edge in the adjacency list is traversed at most once ($O(E)$). State `2` (`Visited`) short-circuits re-traversal.                                                         |
| **Space Complexity** | $O(V + E)$     | **Adjacency List:** Stores $V$ node lists containing $E$ total directed edge references ($O(V + E)$ space).<br><br>**States Array:** Stores state values for $V$ courses ($O(V)$ space).<br><br>**Recursion Stack:** In the worst case (a single linear dependency chain $0 \to 1 \to 2 \dots \to V-1$), the DFS recursion call stack reaches a depth of $O(V)$.  <br><br>Therefore, total auxiliary space is $O(V + E)$. |
