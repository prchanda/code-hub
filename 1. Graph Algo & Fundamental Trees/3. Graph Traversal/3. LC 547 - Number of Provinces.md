Question : https://leetcode.com/problems/number-of-provinces/

```cs

public class Solution {
    public int FindCircleNum(int[][] isConnected) {
        int nodes = isConnected.Length;
        int provinces = 0;

        bool[] visited = new bool[nodes];
        for (int index = 0; index < nodes; index++)
        {
            if (!visited[index])
            {
                provinces++;
                DFS(isConnected, index, visited);
            }
        }

        return provinces;
    }

    private void DFS(int[][] isConnected, int node, bool[] visited)
    {
        visited[node] = true;

        for (int i = 0; i < isConnected.Length; i++)
        {
            if (!visited[i] && isConnected[node][i] == 1)
            {
                DFS(isConnected, i, visited);
            }
        }        
    }
}

```


| **Metric**           | **Complexity**     |
| -------------------- | ------------------ |
| **Time Complexity**  | $\mathcal{O}(N^2)$ |
| **Space Complexity** | $\mathcal{O}(N)$   |

### Time Complexity: $\mathcal{O}(N^2)$

- **DFS Visits:** Every node $0$ through $N-1$ is visited by `DFS` exactly once because of the `visited` array guard.
    
- **Neighbor Checks:** For each node, the internal loop runs $N$ times to check connections across the entire row in `isConnected[node]`.
    
- **Total Operations:** $N \text{ nodes} \times N \text{ checks per node} = N^2$ operations.
    

_(Since the input is an $N \times N$ matrix with $N^2$ elements, you must examine each cell in the matrix at least once in the worst case, making $\mathcal{O}(N^2)$ optimal for an adjacency matrix)._

### Space Complexity: $\mathcal{O}(N)$

- **Visited Array:** The `bool[] visited` array requires $\mathcal{O}(N)$ space to track which nodes have been processed.
    
- **Recursion Stack:** In the worst-case scenario (where all nodes are connected sequentially in a single line, like $0 \to 1 \to 2 \to 3$), the call stack depth will reach $N$, taking $\mathcal{O}(N)$ space.
    
- **Total Auxiliary Space:** $\mathcal{O}(N) + \mathcal{O}(N) = \mathcal{O}(N)$.
