You have a graph of `n` nodes. You are given an integer `n` and an array `edges` where `edges[i] = [ai, bi]` indicates that there is an edge between `ai` and `bi` in the graph. Return _the number of connected components in the graph_.

```cs
private int ConnectedComponents(int n, int[][] edges)
{
    List<int>[] graph = new List<int>[n];
    int connectedComponents = 0;

    for (int index = 0; index < n; index++)
    {
        graph[index] = new List<int>();
    }

    foreach (var edge in edges)
    {
        int a = edge[0];
        int b = edge[1];

        graph[a].Add(b);
        graph[b].Add(a);
    }

    bool[] visited = new bool[n];

    for (int node = 0; node < n; node++)
    {
        if (!visited[node])
        {
            connectedComponents++;
            DFS(graph, node, visited);
        }
    }

    return connectedComponents;
}

private void DFS(List<int>[] graph, int node, bool[] visited)
{
    visited[node] = true;
    var neighbours = graph[node];

    foreach (var neighbour in neighbours)
    {
        if (!visited[neighbour])
        {
            DFS(graph, neighbour, visited);
        }
    }
}

```


| Metric               | Complexity | Details                                                                                                                                                                                                                                                                                                                                              |
| -------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | O(n+E)     | **Graph Construction:** Scans n vertices and E edges (`edges.Length`) to build the adjacency list in O(n+E) time.<br><br>**DFS Traversal:** The main loop checks all n nodes (O(n)). Across all DFS calls, every vertex is marked visited once (O(n)) and every undirected edge is checked twice (O(E)).                                             |
| **Space Complexity** | O(n+E)     | **Adjacency List:** Stores n array entries containing 2E total edge pointers, requiring O(n+E) space.<br><br>**Visited Array & Recursion Stack:** The `visited` boolean array takes O(n) space. In the worst case (a single linear component), the recursion call stack reaches a depth of O(n). <br><br>Therefore, total auxiliary space is O(n+E). |
