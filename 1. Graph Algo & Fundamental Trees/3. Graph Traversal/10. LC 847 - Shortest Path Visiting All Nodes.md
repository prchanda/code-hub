Question: https://leetcode.com/problems/shortest-path-visiting-all-nodes/description/

A better graph/example would be:

      0

     / \

    1   2

     \ /

      3

Now consider reaching node `3` through:

0 → 1 → 3

giving:

(3, {0,1,3})

and through:

0 → 2 → 3

giving:

(3, {0,2,3})

**Same current node (`3`), but different visited sets.** That's the actual reason we cannot simply use:

`visited[3]`

Instead, we need:

`visited[3][{0,1,3}]` // We can use `HashSet<int>` to store the states for each node.

"For every node, remember every different set of nodes with which I have previously reached that node."

**HashSet Solution for reference**

```cs
public class Solution
{
    public int ShortestPathLength(int[][] graph)
    {
        int n = graph.Length;

        Queue<(int node, HashSet<int> visited)> queue = new Queue<(int node, HashSet<int> visited)>();
        Dictionary<int, HashSet<string>> visitedStates = new Dictionary<int, HashSet<string>>();

        // Multi-source BFS: start from every node.
        for (int i = 0; i < n; i++)
        {
            HashSet<int> visited = new HashSet<int> { i };
            queue.Enqueue((i, visited));

            visitedStates[i] = new HashSet<string>
            {
                CreateKey(visited)
            };
        }

        int distance = 0;

        while (queue.Count > 0)
        {
            int size = queue.Count;

            for (int i = 0; i < size; i++)
            {
                var (node, visited) = queue.Dequeue();

                if (visited.Count == n)
                    return distance;

                foreach (int neighbour in graph[node])
                {
                    HashSet<int> newVisited = new HashSet<int>(visited);
                    newVisited.Add(neighbour);
                    string key = CreateKey(newVisited);

                    // Add() returns false if this state already exists.
                    if (!visitedStates[neighbour].Add(key))
                        continue;

                    queue.Enqueue((neighbour, newVisited));
                }
            }

            distance++;
        }

        return -1;
    }

    private string CreateKey(HashSet<int> visited)
    {
        return string.Join(",", visited.OrderBy(x => x));
    }
}
```

### Complexity Analysis

**Time Complexity: $\mathcal{O}(2^N \cdot N^3 \log N)$**

- **Total States:** There are $2^N$ possible subsets of visited nodes and $N$ possible ending nodes, leading to $\mathcal{O}(2^N \cdot N)$ distinct state pairs.
    
- **Cost Per Transition:** For each state, copying the `HashSet` takes $\mathcal{O}(N)$, and `CreateKey` sorts the set, taking $\mathcal{O}(N \log N)$ time.
    
- **Total:** $2^N \cdot N \text{ states} \times (N \text{ transitions} \times N \log N \text{ work}) = \mathcal{O}(2^N \cdot N^3 \log N)$.
    

**Space Complexity: $\mathcal{O}(2^N \cdot N^2)$**

- **Queue & HashSets:** The BFS queue can hold up to $\mathcal{O}(2^N \cdot N)$ active states. Each state stores its own `HashSet<int>` of size up to $N$, consuming $\mathcal{O}(2^N \cdot N^2)$ space.
    
- **Visited Map:** `visitedStates` stores up to $2^N$ string keys per node, each key string taking $\mathcal{O}(N)$ memory, which also contributes $\mathcal{O}(2^N \cdot N^2)$ space.


### Bitmask solution

```cs
public class Solution 
{
    public int ShortestPathLength(int[][] graph) 
    {
        int noOfNodes = graph.Length;
        // All bits need to be set. For example for 3 nodes 1<<nodes would produce 1000
        // subtracting 1 will invert the bits making it 111 which is our target bitmask
        int targetMask = (1 << noOfNodes) - 1;
        
        /* For `n` nodes, each node has 2 choices:
	        node 0 → visited / not visited
			node 1 → visited / not visited
			node 2 → visited / not visited
			
			which is: 2^n possible subsets, 1 << noOfNodes is another way of writing it
		*/

        bool[,] visited = new bool[noOfNodes, 1 << noOfNodes];
        Queue<(int node, int mask)> queue = new Queue<(int, int)>();
        int distance = 0;

        // Initialize BFS from all starting nodes simultaneously
        for (int index = 0; index < noOfNodes; index++)
        {
            int mask = 1 << index; // ✅ Set the bit for the starting node
            visited[index, mask] = true;
            queue.Enqueue((index, mask));
        }

        // Multi-source BFS
        while (queue.Count > 0)
        {
            int size = queue.Count;
            for (int i = 0; i < size; i++)
            {
                var (node, mask) = queue.Dequeue();

                if (mask == targetMask)
                {
                    return distance;
                }

                foreach (var neighbour in graph[node])
                {
                    int newMask = mask | (1 << neighbour);                    
                    
                    if (!visited[neighbour, newMask])
                    {
                        visited[neighbour, newMask] = true;
                        queue.Enqueue((neighbour, newMask));
                    }
                }
            }
            distance++;
        }

        return -1;
    }
}
```



`visited[3][{0,2,3}]`

And this is exactly what eventually becomes:

visited[node, mask]    // each node can be either visited or unvisited represented by 1 or 0. Hence bitmask is used to store the states

### Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \cdot 2^N)$
    
    - There are $N$ nodes and $2^N$ possible visited states (masks).        
    - The maximum number of total states in the BFS queue is $N \cdot 2^N$.        
    - For each state, we iterate over its neighbors. Across all states, this sums to $\mathcal{O}(N \cdot 2^N + E \cdot 2^N) = \mathcal{O}(N \cdot 2^N)$.
        
- **Space Complexity:** $\mathcal{O}(N \cdot 2^N)$
    
    - The `visited` 2D array and the BFS `queue` both store at most $N \cdot 2^N$ states.
