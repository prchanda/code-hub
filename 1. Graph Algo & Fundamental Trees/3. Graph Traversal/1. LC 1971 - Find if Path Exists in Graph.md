Question: https://leetcode.com/problems/find-if-path-exists-in-graph/

```cs
public class Solution {
    public bool ValidPath(int n, int[][] edges, int source, int destination) {
        List<int>[] graph = new List<int>[n];

        for(int index=0; index<n; index++)
        {
            graph[index] = new List<int>();
        }

        foreach(var edge in edges)
        {
            int a = edge[0];
            int b = edge[1];

            graph[a].Add(b);
            graph[b].Add(a);
        }

        bool[] visited = new bool[n];
        return DFS(graph, source, destination, visited);
    }

    private bool DFS(List<int>[] graph, int source, int destination, bool[] visited)
    {
        if(source == destination)
            return true;

        visited[source] = true;

        foreach(int neighbour in graph[source])
        {
            if(visited[neighbour])
                continue;
            if(DFS(graph, neighbour, destination, visited))
                return true;
        }
        return false;
    }
}   
```


| **Metric**           | **Complexity** | **Details**                                                                                                                                                                                                                                                                                                                                                       |
| -------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | $O(V + E)$     | **Graph Construction:** Scans $V$ vertices and $E$ edges once to construct the adjacency list, taking $O(V + E)$ time.<br><br>**DFS Traversal:** Visits each vertex at most once ($O(V)$) and explores each undirected edge at most twice across all adjacency lists ($O(E)$).                                                                                    |
| **Space Complexity** | $O(V + E)$     | **Adjacency List:** Stores $V$ node entries and $2E$ total edge connections, requiring $O(V + E)$ space.  <br><br>**Visited Array & Recursion Stack:** The `visited` boolean array requires $O(V)$ space. In the worst case (a single linear chain), the recursion call stack reaches a depth of $O(V)$.  <br><br>Therefore, total auxiliary space is $O(V + E)$. |
