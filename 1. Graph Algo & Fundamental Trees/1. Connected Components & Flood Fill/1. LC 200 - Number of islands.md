
Question : https://leetcode.com/problems/number-of-islands/description/

**Approach 1: DFS Solution** (Recursion Stack)

```cs
public class Solution {
    public int NumIslands(char[][] grid) {
        // Safely guard against empty array before checking grid[0]
        if (grid == null || grid.Length == 0 || grid[0].Length == 0)
            return 0;

        int islands = 0;
        int rows = grid.Length;
        int cols = grid[0].Length;

        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < cols; col++)
            {
                if (grid[row][col] == '1')
                {
                    islands++;
                    DFS(grid, row, col, rows, cols);
                }
            }
        }
        return islands;
    }

    private void DFS(char[][] grid, int row, int col, int rows, int cols)
    {
        if (row < 0 || row >= rows || col < 0 || col >= cols || grid[row][col] == '0')
            return;

        grid[row][col] = '0'; // Sink the island cell
        DFS(grid, row - 1, col, rows, cols);
        DFS(grid, row + 1, col, rows, cols);
        DFS(grid, row, col - 1, rows, cols);
        DFS(grid, row, col + 1, rows, cols);
    }
}
```



- **Grid Mutation:** Sinking land from `'1'` to `'0'` avoids needing an extra `bool[,] visited` matrix. In coding interviews, always clarify with the interviewer whether mutating the input grid is allowed. If you aren't permitted to modify the input, you would need a separate `visited` matrix or restore the grid values before returning.
    
- **Stack Overflow Risk:** For extremely large grid dimensions, explicit Breadth-First Search (BFS) using a `Queue<(int, int)>` or a Disjoint Set Union (DSU / Union-Find) approach avoids recursion limit errors.

**Approach 2: Using auxiliary space**

```cs
public class Solution {
    public int NumIslands(char[][] grid) {
        if (grid == null || grid.Length == 0 || grid[0].Length == 0)
            return 0;

        int rows = grid.Length;
        int cols = grid[0].Length;
        bool[,] visited = new bool[rows, cols];
        int islands = 0;

        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < cols; col++)
            {
                // Only start DFS if it's land ('1') AND hasn't been visited yet
                if (grid[row][col] == '1' && !visited[row, col])
                {
                    islands++;
                    DFS(grid, visited, row, col, rows, cols);
                }
            }
        }

        return islands;
    }

    private void DFS(char[][] grid, bool[,] visited, int row, int col, int rows, int cols)
    {
        // Base condition: bounds check, water check ('0'), OR already visited
        if (row < 0 || row >= rows || col < 0 || col >= cols || grid[row][col] == '0' || visited[row, col])
            return;

        // Mark current cell as visited instead of sinking '1' -> '0'
        visited[row, col] = true;

        // Explore 4-directional neighbors
        DFS(grid, visited, row - 1, col, rows, cols);
        DFS(grid, visited, row + 1, col, rows, cols);
        DFS(grid, visited, row, col - 1, rows, cols);
        DFS(grid, visited, row, col + 1, rows, cols);
    }
}
```

### Complexity Comparison

| **Metric**           | **In-Place Mutation**          | **Explicit visited Matrix**                             |
| -------------------- | ------------------------------ | ------------------------------------------------------- |
| **Time Complexity**  | $O(m \times n)$                | $O(m \times n)$                                         |
| **Space Complexity** | $O(m \times n)$ _(Call stack)_ | $O(m \times n)$ _(Call stack + $O(m \times n)$ matrix)_ |
| **Input Grid**       | Mutated                        | **Unmodified**                                          |

**Approach 3: Using BFS (Queue)**

```cs
public class Solution {
    public int NumIslands(char[][] grid) {
        if (grid == null || grid.Length == 0 || grid[0].Length == 0)
            return 0;

        int islands = 0;
        int rows = grid.Length;
        int cols = grid[0].Length;

        // Direction vectors for Up, Down, Left, Right moves
        int[][] directions = new int[][] {
            new int[] { -1, 0 },
            new int[] { 1, 0 },
            new int[] { 0, -1 },
            new int[] { 0, 1 }
        };

        for (int r = 0; r < rows; r++)
        {
            for (int c = 0; c < cols; c++)
            {
                if (grid[r][c] == '1')
                {
                    islands++;
                    grid[r][c] = '0'; // Sink starting land immediately

                    Queue<(int row, int col)> queue = new Queue<(int, int)>();
                    queue.Enqueue((r, c));

                    while (queue.Count > 0)
                    {
                        var (currRow, currCol) = queue.Dequeue();
                        
                        foreach (var dir in directions)
                        {
                            int nr = currRow + dir[0];
                            int nc = currCol + dir[1];

                            // Check boundaries and if neighbor is land ('1')
                            if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == '1')
                            {
                                grid[nr][nc] = '0'; // MARK VISITED HERE (critical!)
                                queue.Enqueue((nr, nc));
                            }
                        }
                    }
                }
            }
        }

        return islands;
    }
}
```


## Summary

|**Action**|**Purpose**|
|---|---|
|**Marking as `'0'`**|Prevents other cells from adding this land to the queue a second time (_prevents infinite loops/duplicates_).|
|**Enqueuing the cell**|Allows us to expand outwards from this land to find its _other_ connected neighbors (_continues the search_).|


## Why Choose BFS over DFS?

| **Feature**             | **DFS (Depth-First Search)**                 | **BFS (Breadth-First Search)**   |
| ----------------------- | -------------------------------------------- | -------------------------------- |
| **Data Structure**      | Call Stack (Recursion)                       | `Queue` (Iterative)              |
| **Stack Overflow Risk** | **Yes**, on large grids ($1000 \times 1000$) | **No**, uses heap memory safely  |
| **Exploration Style**   | Explores deep down one path first            | Explores layer-by-layer outwards |


## Iterative version of DFS


```cs
public class Solution
{
    public int NumIslands(char[][] grid)
    {
        if (grid == null || grid.Length == 0) 
            return 0;

        int rows = grid.Length;
        int cols = grid[0].Length;
        int islands = 0;

        Stack<(int row, int col)> stack = new Stack<(int row, int col)>();

        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < cols; col++)
            {
                if (grid[row][col] == '1')
                {
                    islands++;
                    stack.Push((row, col));

                    while (stack.Count > 0)
                    {
                        var (newRow, newCol) = stack.Pop();

                        // Boundary and water check
                        if (newRow < 0 || newRow >= rows || 
                            newCol < 0 || newCol >= cols || 
                            grid[newRow][newCol] == '0')
                        {
                            continue;
                        }

                        // Mark visited
                        grid[newRow][newCol] = '0';

                        // Push 4 directional neighbors
                        stack.Push((newRow - 1, newCol));
                        stack.Push((newRow + 1, newCol));
                        stack.Push((newRow, newCol - 1));
                        stack.Push((newRow, newCol + 1));
                    }
                }
            }
        }

        return islands;
    }
}
```

**Note**
Easiest way to convert a recursive DFS to iterative DFS is by following process:

1. Blindly replace the recursive DFS call with stack push.
2. Replace recursive DFS function call with **while(stack.Count > 0)**
3. Followed by pop action which represents the recursive DFS function params.
4. Then follow the other logic as-is.
