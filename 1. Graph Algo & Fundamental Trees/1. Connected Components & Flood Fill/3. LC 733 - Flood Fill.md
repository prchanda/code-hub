Question: https://leetcode.com/problems/flood-fill/description/

```cs
public class Solution {
    public int[][] FloodFill(int[][] image, int sr, int sc, int color) {
        if (image == null || image.Length == 0 || image[0].Length == 0)
            return image;

        int originalColor = image[sr][sc];

        // Early return if target color is already the same as starting color
        if (originalColor == color)
            return image;

        int rows = image.Length;
        int cols = image[0].Length;

        DFS(image, sr, sc, rows, cols, originalColor, color);
        return image;
    }

    private void DFS(int[][] image, int sr, int sc, int rows, int cols, int originalColor, int color) {
        // Base Condition: Out of bounds OR cell is not the original target color
        if (sr < 0 || sr >= rows || sc < 0 || sc >= cols || image[sr][sc] != originalColor)
            return;

        // Change the pixel color
        image[sr][sc] = color;

        // Explore 4-directional neighbors
        DFS(image, sr - 1, sc, rows, cols, originalColor, color);
        DFS(image, sr + 1, sc, rows, cols, originalColor, color);
        DFS(image, sr, sc - 1, rows, cols, originalColor, color);
        DFS(image, sr, sc + 1, rows, cols, originalColor, color);
    }
}
```

## Complexity Analysis

|**Metric**|**Complexity**|**Explanation**|
|---|---|---|
|**Time Complexity**|$O(m \times n)$|In the worst case, all pixels have the `originalColor` and are visited once.|
|**Space Complexity**|$O(m \times n)$|In the worst case (e.g., a serpentine path of the same color), the recursion stack depth reaches $m \times n$.|
