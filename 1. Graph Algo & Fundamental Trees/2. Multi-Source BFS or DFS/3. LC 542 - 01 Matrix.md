Question : https://leetcode.com/problems/01-matrix/description/

```cs
public class Solution
{
    public int[][] UpdateMatrix(int[][] mat)
    {
        int rows = mat.Length;
        int cols = mat[0].Length;

        int[][] result = new int[rows][];

        for (int row = 0; row < rows; row++)
        {
            result[row] = new int[cols];

            for (int col = 0; col < cols; col++)
            {
                result[row][col] = mat[row][col] == 0 ? 0 : -1;
            }
        }

        int[,] directions =
        {
            {-1, 0},
            {1, 0},
            {0, -1},
            {0, 1}
        };

        Queue<(int row, int col)> queue = new();

        // All zeros are our sources
        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < cols; col++)
            {
                if (mat[row][col] == 0)
                {
                    queue.Enqueue((row, col));
                }
            }
        }

        // Multi-source BFS
        while (queue.Count > 0)
        {
            var (row, col) = queue.Dequeue();

            for (int dir = 0; dir < 4; dir++)
            {
                int newRow = row + directions[dir, 0];
                int newCol = col + directions[dir, 1];

                if (newRow < 0 || newRow >= rows ||
                    newCol < 0 || newCol >= cols)
                    continue;

                // Already visited
                if (result[newRow][newCol] != -1)
                    continue;

                result[newRow][newCol] = result[row][col] + 1;

                queue.Enqueue((newRow, newCol));
            }
        }

        return result;
    }
}
```



| **Metric**           | **Complexity**  | **Details**                                                                                                                                                                                                                                                               |
| -------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Time Complexity**  | $O(m \times n)$ | **Phase 1 (Grid Scan):** Scans all $m \times n$ cells once to initialize the `result` matrix and enqueue all `0`s.  <br>  <br>**Phase 2 (Multi-Source BFS):** Every cell is enqueued and dequeued at most once. Each cell performs $O(1)$ neighbor checks (4 directions). |
| **Space Complexity** | $O(m \times n)$ | **Result Matrix:** Stores the distance for every cell, requiring $O(m \times n)$ space.  <br>  <br>**Queue:** Can contain up to $O(m \times n)$ cells in the worst case, requiring $O(m \times n)$ space.  <br>  <br>Therefore, total auxiliary space is $O(m \times n)$. |
